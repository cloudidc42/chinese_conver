# ภาษาจีนกลาง Part 042: คำบอกลักษณะ (Aspect Particles 了着过)
## 步骤 411-420 | ระดับ: กลาง (Intermediate)

## 🎯 วัตถุประสงค์การเรียนรู้

หลังจากเรียนจบ Part นี้ ผู้เรียนจะสามารถ:
1. เข้าใจความแตกต่างระหว่าง 了 (le), 着 (zhe), 过 (guò)
2. ใช้ 了 บอกความสำเร็จหรือการเปลี่ยนสถานะได้ถูกต้อง
3. ใช้ 着 แสดงสถานะต่อเนื่องหรือกำลังดำเนินอยู่
4. ใช้ 过 บอกประสบการณ์ในอดีตที่เคยเกิดขึ้น
5. หลีกเลี่ยงข้อผิดพลาดที่พบบ่อยในการใช้ Aspect Particles

## 📝 ไวยากรณ์: Aspect Particles

### 步骤 411: 了 (le) - ความสำเร็จและการเปลี่ยนสถานะ

**了 (le)** มีสองหน้าที่หลัก:

#### หน้าที่ที่ 1: 动态助词 (Verbal 了) - บอกความสำเร็จ
วางหลังกริยา แสดงว่าการกระทำสำเร็จ/เสร็จสิ้น

**โครงสร้าง:** 主语 + 动词 + **了** + 宾语
```
ประธาน + กริยา + 了 + กรรม
```

**ตัวอย่าง:**
1. 我吃**了**饭。Wǒ chī **le** fàn. → ฉันกินข้าวแล้ว
2. 他买**了**一本书。Tā mǎi **le** yī běn shū. → เขาซื้อหนังสือเล่มหนึ่งแล้ว
3. 她写**了**三封信。Tā xiě **le** sān fēng xìn. → เธอเขียนจดหมายสามฉบับแล้ว
4. 我们看**了**电影。Wǒmen kàn **le** diànyǐng. → พวกเราดูภาพยนตร์แล้ว

#### หน้าที่ที่ 2: 语气助词 (Sentence-final 了) - บอกการเปลี่ยนสถานะ
วางท้ายประโยค แสดงว่าสถานการณ์เปลี่ยนแปลงไปจากเดิม

**ตัวอย่าง:**
1. 他来**了**。Tā lái **le**. → เขามาแล้ว (เมื่อกี้ยังไม่มา แต่ตอนนี้มาแล้ว)
2. 春天到**了**。Chūntiān dào **le**. → ฤดูใบไม้ผลิมาถึงแล้ว
3. 我懂**了**。Wǒ dǒng **le**. → ฉันเข้าใจแล้ว
4. 天黑**了**。Tiān hēi **le**. → ฟ้ามืดแล้ว

### 步骤 412: กฎการใช้ 了 20+ ข้อ

**กฎที่ 1: ใช้กับกริยาที่สำเร็จแล้ว**
- ✅ 他做**了**作业。Tā zuò **le** zuòyè. → เขาทำการบ้านแล้ว
- ✅ 我买**了**东西。Wǒ mǎi **le** dōngxi. → ฉันซื้อของแล้ว

**กฎที่ 2: ใช้กับกริยาที่มีกรรมแน่นอน**
- ✅ 我吃**了**三个苹果。Wǒ chī **le** sān gè píngguǒ. → ฉันกินแอปเปิ้ลสามลูกแล้ว
- ✅ 她看**了**一部电影。Tā kàn **le** yī bù diànyǐng. → เธอดูหนังเรื่องหนึ่งแล้ว

**กฎที่ 3: ไม่ใช้กับกริยาสภาพ (Stative verbs)**
- ❌ 我知道**了**中文。→ ✅ 我知道中文了。Wǒ zhīdào Zhōngwénle. → ฉันรู้จักภาษาจีนแล้ว
- ❌ 她爱**了**他。→ ✅ 她爱他了。Tā ài tā le. → เธอรักเขาแล้ว

**กฎที่ 4: ประโยคปฏิเสธใช้ 没有 ไม่ใช้ 了**
- ✅ 我没有吃饭。Wǒ méiyǒu chī fàn. → ฉันไม่ได้กินข้าว (ปฏิเสธ)
- ❌ 我没有吃了饭。(ผิด)

**กฎที่ 5: คำถาม V了...没有?**
- 你吃了饭**没有**? Nǐ chī le fàn **méiyǒu**? → คุณกินข้าวแล้วหรือยัง?
- 他来**了没有**? Tā lái **le méiyǒu**? → เขามาแล้วหรือยัง?

**กฎที่ 6: ใช้กับเงื่อนไข (Conditional)**
- 你吃**了**饭，再走。Nǐ chī **le** fàn, zài zǒu. → กินข้าวก่อนค่อยไปนะ
- 你休息**了**再学习。Nǐ xiūxi **le** zài xuéxí. → พักแล้วค่อยเรียนนะ

### 步骤 413: 着 (zhe) - สถานะต่อเนื่อง

**着 (zhe)** แสดงว่า:
1. การกระทำกำลังดำเนินอยู่ (คล้าย -ing ในอังกฤษ)
2. สถาพหรือสภาวะที่ยังคงอยู่

#### การใช้ 1: สถานะต่อเนื่อง
**โครงสร้าง:** 主语 + 动词 + **着** + (宾语)

**ตัวอย่าง:**
1. 他穿**着**一件红色的衣服。Tā chuān **zhe** yī jiàn hóngsè de yīfú. → เขากำลังสวมเสื้อสีแดงอยู่
2. 门开**着**呢。Mén kāi **zhe** ne. → ประตูเปิดอยู่นะ
3. 她手里拿**着**一本书。Tā shǒu lǐ ná **zhe** yī běn shū. → เธอถือหนังสือเล่มหนึ่งอยู่ในมือ
4. 他们坐**着**聊天。Tāmen zuò **zhe** liáotiān. → พวกเขานั่งคุยกันอยู่

#### การใช้ 2: V1着V2 - ทำกริยา 1 ขณะทำกริยา 2
**โครงสร้าง:** 主语 + V1 + 着 + V2

**ตัวอย่าง:**
1. 她**笑着**说话。Tā **xiào zhe** shuōhuà. → เธอพูดพลางยิ้ม
2. 他**跑着**回家了。Tā **pǎo zhe** huí jiā le. → เขาวิ่งกลับบ้าน
3. 我们**走着**去学校。Wǒmen **zǒu zhe** qù xuéxiào. → พวกเราเดินไปโรงเรียน
4. 他**唱着歌**做饭。Tā **chàng zhe gē** zuòfàn. → เขาทำอาหารพลางร้องเพลง

### 步骤 414: 过 (guò) - ประสบการณ์

**过 (guò)** แสดงว่าเคยมีประสบการณ์นั้นในอดีต (ไม่ระบุเวลาชัดเจน)

**โครงสร้าง:** 主语 + 动词 + **过** + (宾语)

**ตัวอย่าง:**
1. 我去**过**中国。Wǒ qù **guò** Zhōngguó. → ฉันเคยไปจีน
2. 她吃**过**泰国菜。Tā chī **guò** Tàiguó cài. → เธอเคยกินอาหารไทย
3. 他学**过**法语。Tā xué **guò** Fǎyǔ. → เขาเคยเรียนภาษาฝรั่งเศส
4. 我们见**过**面。Wǒmen jiàn **guò** miàn. → พวกเราเคยพบกัน

**ปฏิเสธ 过: 没有 + V + 过**
1. 我没有去**过**日本。Wǒ méiyǒu qù **guò** Rìběn. → ฉันไม่เคยไปญี่ปุ่น
2. 她没有吃**过**榴莲。Tā méiyǒu chī **guò** liúlián. → เธอไม่เคยกินทุเรียน
3. 他没有学**过**中文。Tā méiyǒu xué **guò** Zhōngwén. → เขาไม่เคยเรียนภาษาจีน

**ถาม 过: V + 过 + ... + 吗/没有?**
1. 你去**过**中国**吗**? Nǐ qù **guò** Zhōngguó **ma**? → คุณเคยไปจีนไหม?
2. 你吃**过**北京烤鸭**没有**? Nǐ chī **guò** Běijīng kǎoyā **méiyǒu**? → คุณเคยกินเป็ดปักกิ่งไหม?

### 步骤 415: เปรียบเทียบ 了 vs 着 vs 过

| | 了 (le) | 着 (zhe) | 过 (guò) |
|--|--------|---------|---------|
| **ความหมาย** | เสร็จสิ้น/เปลี่ยนสถานะ | กำลังดำเนินอยู่/สถานะต่อเนื่อง | เคยมีประสบการณ์ |
| **เวลา** | อดีต/ปัจจุบัน | ปัจจุบัน/ต่อเนื่อง | อดีต (ไม่ระบุเวลา) |
| **โฟกัส** | ผลลัพธ์ | สถานะ | ประสบการณ์ |
| **ปฏิเสธ** | 没有 + V | 没有 + V + 着 | 没有 + V + 过 |

**ตัวอย่างเปรียบเทียบ:**
- 我吃**了**饭。Wǒ chī **le** fàn. → ฉันกินข้าวแล้ว (เสร็จแล้ว)
- 我吃**着**饭呢。Wǒ chī **zhe** fàn ne. → ฉันกำลังกินข้าวอยู่ (กำลังกินอยู่)
- 我吃**过**这道菜。Wǒ chī **guò** zhè dào cài. → ฉันเคยกินอาหารจานนี้ (ประสบการณ์)

## 💬 บทสนทนา

### บทสนทนา 1: เล่าเรื่องที่ทำมา (ใช้ 了)

**小王 (Xiǎo Wáng):** 你今天做了什么？
Nǐ jīntiān zuò le shénme?
วันนี้คุณทำอะไรบ้างครับ?

**小李 (Xiǎo Lǐ):** 我早上起了床，吃了早饭，然后去了学校。
Wǒ zǎoshang qǐ le chuáng, chī le zǎofàn, ránhòu qù le xuéxiào.
ฉันตื่นนอน กินข้าวเช้า แล้วก็ไปโรงเรียนค่ะ

**小王:** 下午呢？做了作业没有？
Xiàwǔ ne? Zuò le zuòyè méiyǒu?
แล้วตอนบ่ายล่ะครับ? ทำการบ้านเสร็จแล้วไหมครับ?

**小李:** 做了！还看了一部电影。你呢？
Zuò le! Hái kàn le yī bù diànyǐng. Nǐ ne?
ทำเสร็จแล้วค่ะ! แล้วก็ดูหนังด้วยหนึ่งเรื่องค่ะ แล้วคุณล่ะ?

**小王:** 我只是在家休息了一天，什么都没做。
Wǒ zhǐshì zài jiā xiūxi le yītiān, shénme dōu méi zuò.
ผมแค่พักอยู่บ้านหนึ่งวัน ไม่ได้ทำอะไรเลยครับ

### บทสนทนา 2: อธิบายสถานะ (ใช้ 着)

**妈妈 (Māma):** 宝贝，你在干什么呢？
Bǎobèi, nǐ zài gàn shénme ne?
ลูก กำลังทำอะไรอยู่ลูก?

**孩子 (Háizi):** 我坐着看书呢，妈妈。
Wǒ zuò zhe kàn shū ne, māma.
หนูกำลังนั่งอ่านหนังสืออยู่ค่ะ แม่

**妈妈:** 窗户开着吗？外面很冷哦。
Chuānghù kāi zhe ma? Wàimiàn hěn lěng ō.
หน้าต่างเปิดอยู่ไหมลูก? ข้างนอกหนาวนะ

**孩子:** 开着呢，我等一下关。现在身上穿着厚衣服，不冷。
Kāi zhe ne, wǒ děng yīxià guān. Xiànzài shēn shàng chuān zhe hòu yīfú, bù lěng.
เปิดอยู่ค่ะ หนูจะปิดทีหลัง ตอนนี้ใส่เสื้อหนาอยู่ ไม่หนาวค่ะ

**妈妈:** 好，你爸爸等着你吃晚饭呢，快来！
Hǎo, nǐ bàba děng zhe nǐ chī wǎnfàn ne, kuài lái!
โอเคนะลูก พ่อกำลังรอกินข้าวเย็นด้วยกันอยู่ รีบมาเลยนะ!

### บทสนทนา 3: เล่าประสบการณ์ (ใช้ 过)

**旅行达人 (Lǚxíng dárén):** 你去过中国哪些地方？
Nǐ qù guò Zhōngguó nǎxiē dìfang?
คุณเคยไปที่ไหนในจีนบ้างครับ?

**游客 (Yóukè):** 我去过北京和上海。还没去过西安。
Wǒ qù guò Běijīng hé Shànghǎi. Hái méi qù guò Xī'ān.
ฉันเคยไปปักกิ่งและเซี่ยงไฮ้ค่ะ แต่ยังไม่เคยไปซีอาน

**旅行达人:** 北京的烤鸭你吃过吗？
Běijīng de kǎoyā nǐ chī guò ma?
คุณเคยกินเป็ดปักกิ่งไหมครับ?

**游客:** 吃过！超好吃！你去过泰国吗？
Chī guò! Chāo hǎo chī! Nǐ qù guò Tàiguó ma?
เคยค่ะ! อร่อยมากเลย! คุณเคยไปเมืองไทยไหมครับ?

**旅行达人:** 还没有，但我一直想去。听说泰国菜很好吃！你吃过什么让你印象深刻的食物吗？
Hái méiyǒu, dàn wǒ yīzhí xiǎng qù. Tīng shuō Tàiguó cài hěn hǎo chī! Nǐ chī guò shénme ràng nǐ yìnxiàng shēnkè de shíwù ma?
ยังไม่เคยไปเลยครับ แต่อยากไปมาตลอด ได้ยินว่าอาหารไทยอร่อยมาก! คุณเคยกินอาหารอะไรที่ประทับใจเป็นพิเศษไหมครับ?

### บทสนทนา 4: ผสม 了/着/过

**朋友甲 (Péngyǒu jiǎ):** 你看过那部新电影吗？
Nǐ kàn guò nà bù xīn diànyǐng ma?
คุณเคยดูหนังเรื่องใหม่นั้นไหม?

**朋友乙 (Péngyǒu yǐ):** 看过了！昨天看的。电影院里坐着很多人呢。
Kàn guò le! Zuótiān kàn de. Diànyǐngyuàn lǐ zuò zhe hěn duō rén ne.
เคยดูแล้วค่ะ! ดูเมื่อวาน ในโรงหนังมีคนนั่งเต็มเลยนะ

**朋友甲:** 好看吗？我昨天等着买票，没买到。
Hǎo kàn ma? Wǒ zuótiān děng zhe mǎi piào, méi mǎi dào.
ดีไหม? เมื่อวานฉันรอซื้อตั๋วแต่ซื้อไม่ได้

**朋友乙:** 超好看！我已经看了两遍了！你快去买票吧！
Chāo hǎo kàn! Wǒ yǐjīng kàn le liǎng biàn le! Nǐ kuài qù mǎi piào ba!
ดีมากเลย! ฉันดูไปแล้วสองรอบแล้ว! รีบไปซื้อตั๋วเลยนะ!

### บทสนทนา 5: ที่โรงพยาบาล

**医生 (Yīshēng):** 你最近睡眠怎么样？
Nǐ zuìjìn shuìmián zěnme yàng?
ช่วงนี้การนอนหลับของคุณเป็นยังไงบ้างครับ?

**患者 (Huànzhě):** 不太好，我最近睡着了之后容易醒。
Bú tài hǎo, wǒ zuìjìn shuì zháo le zhīhòu róngyì xǐng.
ไม่ค่อยดีเลยครับ ช่วงนี้พอหลับแล้วก็ตื่นง่าย

**医生:** 你以前有过这种情况吗？
Nǐ yǐqián yǒu guò zhèzhǒng qíngkuàng ma?
คุณเคยมีอาการแบบนี้มาก่อนไหม?

**患者 (Huànzhě):** 没有。这是第一次。我已经喝了很多药了，但没有好。
Méiyǒu. Zhè shì dì yī cì. Wǒ yǐjīng hē le hěn duō yào le, dàn méiyǒu hǎo.
ไม่เคยครับ นี่เป็นครั้งแรก ผมกินยาไปเยอะมากแล้วแต่ก็ไม่หาย

### บทสนทนา 6: การช็อปปิ้ง

**朋友 (Péngyǒu):** 你今天买了什么东西？
Nǐ jīntiān mǎi le shénme dōngxi?
วันนี้คุณซื้ออะไรมาบ้าง?

**我 (Wǒ):** 我买了一件衬衫，还买了一双鞋。店员穿着制服，很专业。
Wǒ mǎi le yī jiàn chènshān, hái mǎi le yī shuāng xié. Diànyuán chuān zhe zhìfú, hěn zhuānyè.
ฉันซื้อเสื้อเชิ้ตหนึ่งตัว และรองเท้าหนึ่งคู่ พนักงานใส่ยูนิฟอร์มดูเป็นมืออาชีพมาก

**朋友:** 你以前去过那家店吗？
Nǐ yǐqián qù guò nà jiā diàn ma?
คุณเคยไปร้านนั้นมาก่อนไหม?

**我:** 没有，第一次去。那家店开着大门，感觉很热情。
Méiyǒu, dì yī cì qù. Nà jiā diàn kāi zhe dà mén, gǎnjué hěn rèqíng.
ไม่เคยเลย ไปครั้งแรก ร้านนั้นเปิดประตูใหญ่ไว้ รู้สึกต้อนรับดีมาก

### บทสนทนา 7: ท่องเที่ยว

**导游 (Dǎoyóu):** 大家好！欢迎来到故宫！你们有没有来过这里？
Dàjiā hǎo! Huānyíng lái dào Gùgōng! Nǐmen yǒu méiyǒu lái guò zhèlǐ?
สวัสดีทุกคน! ยินดีต้อนรับสู่พระราชวังต้องห้าม! ทุกคนเคยมาที่นี่กันไหม?

**游客A (Yóukè A):** 我来过一次，十年前。
Wǒ lái guò yī cì, shí nián qián.
ผมเคยมาครั้งหนึ่ง เมื่อสิบปีก่อนครับ

**游客B (Yóukè B):** 我没有来过，第一次来。导游，我们要走多远？
Wǒ méiyǒu lái guò, dì yī cì lái. Dǎoyóu, wǒmen yào zǒu duō yuǎn?
ฉันไม่เคยมาเลย มาครั้งแรกค่ะ ไกด์ เราต้องเดินไกลแค่ไหนคะ?

**导游:** 大概两个小时。大家穿着舒服的鞋了吗？
Dàgài liǎng gè xiǎoshí. Dàjiā chuān zhe shūfú de xié le ma?
ประมาณสองชั่วโมงครับ ทุกคนใส่รองเท้าที่สบายกันแล้วหรือยังครับ?

### บทสนทนา 8: ในออฟฟิศ

**同事A (Tóngshì A):** 你发了邮件没有？
Nǐ fā le yóujiàn méiyǒu?
คุณส่งอีเมลแล้วหรือยัง?

**同事B (Tóngshì B):** 发了，十分钟前发的。老板还在等着回复呢。
Fā le, shí fēnzhōng qián fā de. Lǎobǎn hái zài děng zhe huífù ne.
ส่งแล้วครับ ส่งไปสิบนาทีก่อน เจ้านายกำลังรอรับการตอบกลับอยู่นะครับ

**同事A:** 你以前遇到过这种情况吗？
Nǐ yǐqián yù dào guò zhèzhǒng qíngkuàng ma?
คุณเคยเจอสถานการณ์แบบนี้มาก่อนไหม?

**同事B:** 遇到过几次，不用太担心。老板理解的。
Yù dào guò jǐ cì, bú yòng tài dānxīn. Lǎobǎn lǐjiě de.
เคยเจอมาหลายครั้งแล้วครับ ไม่ต้องกังวลมากเกินไป เจ้านายเข้าใจครับ

## 🔊 ประโยคฝึกออกเสียง (80+ ประโยค)

### ชุดที่ 1: 了 (le) - ความสำเร็จ
1. 我吃了早饭。Wǒ chī le zǎofàn. → ฉันกินข้าวเช้าแล้ว
2. 他写了作业。Tā xiě le zuòyè. → เขาทำการบ้านแล้ว
3. 她买了新衣服。Tā mǎi le xīn yīfú. → เธอซื้อเสื้อผ้าใหม่แล้ว
4. 我们看了电影。Wǒmen kàn le diànyǐng. → พวกเราดูหนังแล้ว
5. 老师讲了新课。Lǎoshī jiǎng le xīn kè. → ครูสอนบทเรียนใหม่แล้ว
6. 他们玩了游戏。Tāmen wán le yóuxì. → พวกเขาเล่นเกมแล้ว
7. 我喝了一杯水。Wǒ hē le yī bēi shuǐ. → ฉันดื่มน้ำหนึ่งแก้วแล้ว
8. 妈妈做了晚饭。Māma zuò le wǎnfàn. → แม่ทำข้าวเย็นแล้ว
9. 爸爸读了报纸。Bàba dú le bàozhǐ. → พ่ออ่านหนังสือพิมพ์แล้ว
10. 她洗了碗。Tā xǐ le wǎn. → เธอล้างจานแล้ว

### ชุดที่ 2: 了 (le) - การเปลี่ยนสถานะ
11. 他长大了。Tā zhǎng dà le. → เขาโตแล้ว
12. 天气变冷了。Tiānqì biàn lěng le. → อากาศเย็นลงแล้ว
13. 花开了。Huā kāi le. → ดอกไม้บานแล้ว
14. 他病了。Tā bìng le. → เขาป่วยแล้ว
15. 我会了！Wǒ huì le! → ฉันทำได้แล้ว!
16. 他们结婚了。Tāmen jiéhūn le. → พวกเขาแต่งงานแล้ว
17. 她毕业了。Tā bìyè le. → เธอจบการศึกษาแล้ว
18. 天亮了。Tiān liàng le. → ฟ้าสว่างแล้ว
19. 雨停了。Yǔ tíng le. → ฝนหยุดแล้ว
20. 电影结束了。Diànyǐng jiéshù le. → หนังจบแล้ว

### ชุดที่ 3: 着 (zhe) - สถานะต่อเนื่อง
21. 他穿着蓝色的衬衫。Tā chuān zhe lánsè de chènshān. → เขาใส่เสื้อเชิ้ตสีน้ำเงินอยู่
22. 门开着。Mén kāi zhe. → ประตูเปิดอยู่
23. 她戴着眼镜。Tā dài zhe yǎnjìng. → เธอใส่แว่นตาอยู่
24. 他手里拿着书。Tā shǒu lǐ ná zhe shū. → เขาถือหนังสือในมืออยู่
25. 灯亮着。Dēng liàng zhe. → ไฟเปิดอยู่
26. 她坐着看电视。Tā zuò zhe kàn diànshì. → เธอนั่งดูโทรทัศน์อยู่
27. 他站着等车。Tā zhàn zhe děng chē. → เขายืนรอรถอยู่
28. 音乐放着呢。Yīnyuè fàng zhe ne. → เพลงกำลังเปิดอยู่นะ
29. 孩子们笑着玩耍。Háizimen xiào zhe wánshuǎ. → เด็กๆ กำลังยิ้มเล่นอยู่
30. 她哭着说话。Tā kū zhe shuōhuà. → เธอร้องไห้พลางพูด

### ชุดที่ 4: 过 (guò) - ประสบการณ์
31. 我去过日本。Wǒ qù guò Rìběn. → ฉันเคยไปญี่ปุ่น
32. 她吃过北京烤鸭。Tā chī guò Běijīng kǎoyā. → เธอเคยกินเป็ดปักกิ่ง
33. 我没有去过澳大利亚。Wǒ méiyǒu qù guò Àodàlìyǎ. → ฉันไม่เคยไปออสเตรเลีย
34. 他学过西班牙语。Tā xué guò Xībānyáyǔ. → เขาเคยเรียนภาษาสเปน
35. 我们以前见过面。Wǒmen yǐqián jiàn guò miàn. → พวกเราเคยพบกันมาก่อน
36. 你爬过长城吗？Nǐ pá guò Chángchéng ma? → คุณเคยปีนกำแพงเมืองจีนไหม?
37. 她没有坐过飞机。Tā méiyǒu zuò guò fēijī. → เธอไม่เคยนั่งเครื่องบิน
38. 我用过这个软件。Wǒ yòng guò zhège ruǎnjiàn. → ฉันเคยใช้ซอฟต์แวร์นี้
39. 他看过这部电影。Tā kàn guò zhè bù diànyǐng. → เขาเคยดูหนังเรื่องนี้
40. 我们住过那家宾馆。Wǒmen zhù guò nà jiā bīnguǎn. → พวกเราเคยพักที่โรงแรมนั้น

### ชุดที่ 5: ประโยคผสม
41. 我以前去过中国，今年又去了一次。Wǒ yǐqián qù guò Zhōngguó, jīnnián yòu qù le yī cì. → ฉันเคยไปจีนมาก่อน ปีนี้ไปอีกครั้งหนึ่ง
42. 她穿着新买的衣服去了聚会。Tā chuān zhe xīn mǎi de yīfú qù le jùhuì. → เธอใส่เสื้อผ้าที่เพิ่งซื้อไปงานปาร์ตี้
43. 他吃过很多国家的菜，日本菜是他最爱的。Tā chī guò hěn duō guójiā de cài, Rìběn cài shì tā zuì ài de. → เขาเคยกินอาหารหลายประเทศ อาหารญี่ปุ่นเป็นที่สุดของเขา
44. 音乐开着呢，她跳着舞唱着歌。Yīnyuè kāi zhe ne, tā tiào zhe wǔ chàng zhe gē. → เพลงกำลังเปิดอยู่ เธอกำลังเต้นพลางร้องเพลง
45. 我没去过那里，但听说很美。Wǒ méi qù guò nàlǐ, dàn tīng shuō hěn měi. → ฉันไม่เคยไปที่นั่น แต่ได้ยินว่าสวยมาก

### บทสนทนา 9: ที่สนามบิน (ใช้ 了/过)

### บทสนทนา 10: คุยเรื่องเรียน (ใช้ 了/着/过 ผสม)

Jiāo le èrshí nián le. Nǐ xué Zhōngwén duō jiǔ le?

**老师:** 是吗？你现在坐着学习，还是站着背单词？

**同学A:** 哈哈，我坐着学习。手里拿着笔记本，认真地做笔记呢。
Hāhā, wǒ zuò zhe xuéxí. Shǒu lǐ ná zhe bǐjìběn, rènzhēn de zuò bǐjì ne.
ฮาๆ ครับ ผมนั่งเรียนอยู่ มือถือสมุดจดบันทึกอยู่ กำลังจดโน้ตอย่างตั้งใจครับ

### บทสนทนา 11: ดูหนังด้วยกัน (ใช้ 了/着/过 ผสม)

**大明:** 好啊！周末有空，我们约起来！
Hǎo a! Zhōumò yǒu kòng, wǒmen yuē qǐlái!

## ✏️ แบบฝึกหัดเพิ่มเติม

### แบบฝึกหัด 6: เลือกประโยคที่ถูกต้อง (选择正确的句子)

เลือก ก หรือ ข ที่ถูกต้อง:

1.  ก. 我没有去了北京。
    ข. 我没有去过北京。
    → คุณไม่เคยไปปักกิ่ง

2.  ก. 她穿着一件蓝色的裙子。
    ข. 她穿了一件蓝色的裙子（现在还穿着）。
    → เธอกำลังใส่กระโปรงสีน้ำเงินอยู่

3.  ก. 他学中文了三年了。
    ข. 他学中文学了三年了。
    → เขาเรียนภาษาจีนมาสามปีแล้ว

4.  ก. 我以前见着他一次。
    ข. 我以前见过他一次。
    → ฉันเคยพบเขาครั้งหนึ่ง

5.  ก. 门关了，请不要进来。（ประตูปิดอยู่）
    ข. 门关着，请不要进来。
    → ประตูปิดอยู่ กรุณาอย่าเข้ามา

**เฉลย:** 1.ข 2.ก 3.ข 4.ข 5.ข

### แบบฝึกหัด 7: เติมประโยคให้สมบูรณ์ด้วย 了/着/过

เติม 了, 着 หรือ 过 ในช่องว่าง (บางประโยคต้องการมากกว่าหนึ่งตัว)

1. 她学___ 英语，现在又在学___ 中文呢。
   (เธอเคยเรียนภาษาอังกฤษ ตอนนี้กำลังเรียนภาษาจีนอยู่)

2. 我吃___三个苹果，肚子有点饱___。
   (ฉันกินแอปเปิ้ลสามลูกแล้ว ท้องอิ่มหน่อยแล้ว)

3. 他站___等公共汽车，等___两个小时___。
   (เขายืนรอรถเมล์อยู่ รอมาสองชั่วโมงแล้ว)

4. 你去___泰国吗？我去___两次___，很喜欢。
   (คุณเคยไปเมืองไทยไหม? ฉันไปแล้วสองครั้ง ชอบมาก)

5. 窗户开___，外面的声音传进来___。
   (หน้าต่างเปิดอยู่ เสียงข้างนอกเข้ามาแล้ว)

**เฉลย:**
1. 过 / 着 (她学**过**英语，现在又在学**着**中文呢。)
2. 了 / 了 (我吃**了**三个苹果，肚子有点饱**了**。)
3. 着 / 了 / 了 (他站**着**等公共汽车，等**了**两个小时**了**。)
4. 过 / 了 / 了 (你去**过**泰国吗？我去**了**两次**了**，很喜欢。)
5. 着 / 了 (窗户开**着**，外面的声音传进来**了**。)

### แบบฝึกหัด 8: เรียงคำให้เป็นประโยค

เรียงคำต่อไปนี้ให้เป็นประโยคที่ถูกต้อง:

1. 了 / 书 / 本 / 我 / 买 / 两 / 这
   → _________
2. 着 / 他 / 帽子 / 戴 / 红色的
   → _________
3. 北京 / 去 / 过 / 你 / 吗？
   → _________
4. 走 / 着 / 她 / 唱歌 / 路
   → _________
5. 这部 / 没有 / 他 / 电影 / 过 / 看
   → _________
