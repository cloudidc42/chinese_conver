## 📝 ไวยากรณ์: Complement Structures

### 步骤 421: Result Complement (结果补语)

**โครงสร้าง:** 动词 + 结果补语 (V + RC)

Result Complement วางต่อจากกริยาหลัก บอกผลลัพธ์ของการกระทำ

**ยืนยัน:** V + RC + (了)
**ปฏิเสธ:** V + 不 + RC (ทำไม่ได้/ไม่สำเร็จ - ศักยภาพ)
         没 + V + RC (ไม่ได้ทำสำเร็จ - อดีต)

#### Result Complements ที่ใช้บ่อย:

**完 (wán) - เสร็จสิ้น**
1. 我写**完**了作业。Wǒ xiě **wán** le zuòyè. → ฉันทำการบ้านเสร็จแล้ว
2. 他吃**完**了饭。Tā chī **wán** le fàn. → เขากินข้าวหมดแล้ว
3. 我没写**完**作业。Wǒ méi xiě **wán** zuòyè. → ฉันทำการบ้านไม่เสร็จ

**好 (hǎo) - ทำเสร็จอย่างดี**
1. 饭做**好**了！Fàn zuò **hǎo** le! → ข้าวทำเสร็จแล้ว!
2. 作业做**好**了没有？Zuòyè zuò **hǎo** le méiyǒu? → ทำการบ้านเสร็จแล้วหรือยัง?
3. 准备**好**了吗？Zhǔnbèi **hǎo** le ma? → เตรียมพร้อมแล้วหรือยัง?

**到 (dào) - ถึง/สำเร็จ**
1. 你找**到**书了吗？Nǐ zhǎo **dào** shū le ma? → คุณหาหนังสือเจอแล้วหรือยัง?
2. 我买**到**票了！Wǒ mǎi **dào** piào le! → ฉันซื้อตั๋วได้แล้ว!
3. 他没找**到**工作。Tā méi zhǎo **dào** gōngzuò. → เขาหางานไม่ได้

**懂 (dǒng) - เข้าใจ**
1. 你听**懂**了吗？Nǐ tīng **dǒng** le ma? → คุณฟังเข้าใจไหม?
2. 我看**懂**了这本书。Wǒ kàn **dǒng** le zhè běn shū. → ฉันอ่านหนังสือเล่มนี้เข้าใจแล้ว
3. 老师说的我听不**懂**。Lǎoshī shuō de wǒ tīng bù **dǒng**. → สิ่งที่ครูพูดฉันฟังไม่เข้าใจ

**见 (jiàn) - มองเห็น/ได้ยิน**
1. 你看**见**他了吗？Nǐ kàn **jiàn** tā le ma? → คุณเห็นเขาแล้วหรือยัง?
2. 我听**见**奇怪的声音。Wǒ tīng **jiàn** qíguài de shēngyīn. → ฉันได้ยินเสียงแปลกๆ
3. 在这里看不**见**山。Zài zhèlǐ kàn bù **jiàn** shān. → ที่นี่มองไม่เห็นภูเขา

**住 (zhù) - จำได้/มั่นคง**
1. 我记**住**了你的名字。Wǒ jì **zhù** le nǐ de míngzi. → ฉันจำชื่อคุณได้แล้ว
2. 抓**住**绳子！Zhuā **zhù** shéngzi! → จับเชือกไว้!
3. 这个词我记不**住**。Zhège cí wǒ jì bù **zhù**. → คำศัพท์นี้ฉันจำไม่ได้

### 步骤 422: Directional Complement (趋向补语)

**趋向补语** บอกทิศทางของการเคลื่อนที่

#### Simple Directional (单纯趋向补语):
- **来 (lái)** - มา (ทิศทางเข้าหาผู้พูด)
- **去 (qù)** - ไป (ทิศทางออกจากผู้พูด)

#### Compound Directional (复合趋向补语):

| ทิศทาง | + 来 (มา) | + 去 (ไป) |
|-------|---------|---------|
| 上 (ขึ้น) | 上来 shàng lái | 上去 shàng qù |
| 下 (ลง) | 下来 xià lái | 下去 xià qù |
| 进 (เข้า) | 进来 jìn lái | 进去 jìn qù |
| 出 (ออก) | 出来 chū lái | 出去 chū qù |
| 回 (กลับ) | 回来 huí lái | 回去 huí qù |
| 过 (ข้าม/ผ่าน) | 过来 guò lái | 过去 guò qù |
| 起 (ลุก) | 起来 qǐ lái | - |

**ตัวอย่างประโยค:**
1. 他**走上来**了。Tā **zǒu shàng lái** le. → เขาเดินขึ้นมาแล้ว
2. 请**走进来**！Qǐng **zǒu jìn lái**! → กรุณาเดินเข้ามา!
3. 他**跑出去**了。Tā **pǎo chū qù** le. → เขาวิ่งออกไปแล้ว
4. 妈妈**回来**了！Māma **huí lái** le! → แม่กลับมาแล้ว!
5. 请**站起来**。Qǐng **zhàn qǐ lái**. → กรุณายืนขึ้น
6. 他们**走过来**跟我说话。Tāmen **zǒu guò lái** gēn wǒ shuōhuà. → พวกเขาเดินมาหาฉันเพื่อคุย
7. 她**下来**了。Tā **xià lái** le. → เธอลงมาแล้ว
8. 请把书**拿上来**。Qǐng bǎ shū **ná shàng lái**. → กรุณาหยิบหนังสือขึ้นมา

### 步骤 423: Degree Complement (程度补语)

**程度补语** วัดระดับหรือความเข้มข้นของการกระทำ

**โครงสร้าง:** 主语 + 动词/形容词 + **得** + 程度补语

**ตัวอย่างกับ 得:**
1. 她跳舞跳**得**很好。Tā tiào wǔ tiào **de** hěn hǎo. → เธอเต้นรำได้ดีมาก
2. 他说汉语说**得**很流利。Tā shuō Hànyǔ shuō **de** hěn liúlì. → เขาพูดภาษาจีนได้คล่องมาก
3. 她跑**得**很快。Tā pǎo **de** hěn kuài. → เธอวิ่งได้เร็วมาก
4. 他写字写**得**很漂亮。Tā xiě zì xiě **de** hěn piàoliang. → เขาเขียนตัวหนังสือได้สวยมาก

**Degree Complements ที่ใช้บ่อย:**
- 得很好 de hěn hǎo → ดีมาก
- 得很快 de hěn kuài → เร็วมาก
- 得很慢 de hěn màn → ช้ามาก
- 得很厉害 de hěn lìhai → เก่งมาก/รุนแรงมาก
- 得不得了 de bùdéliǎo → มากจนไม่ได้เรื่อง
- 极了 jí le → มากที่สุด
- 死了 sǐ le → มากจนตาย (อุปมา)
- 坏了 huài le → แย่มาก / เสียใจมาก

**ตัวอย่างกับ Degree Complement พิเศษ:**
1. 这个菜好吃**极了**。Zhège cài hǎo chī **jí le**. → อาหารจานนี้อร่อยมากที่สุดเลย
2. 今天热**死了**！Jīntiān rè **sǐ le**! → วันนี้ร้อนจนตายเลย!
3. 我饿**死了**！Wǒ è **sǐ le**! → ฉันหิวจนตายเลย!
4. 他高兴**得不得了**！Tā gāoxìng **de bùdéliǎo**! → เขาดีใจมากจนหยุดไม่ได้เลย!

### 步骤 424: Potential Complement (可能补语)

**可能补语** บอกว่า "ทำได้" หรือ "ทำไม่ได้"

**โครงสร้าง:**
- ทำได้: V + **得** + RC
- ทำไม่ได้: V + **不** + RC

**ตัวอย่างคู่:**

| ทำได้ | ทำไม่ได้ |
|------|---------|
| 听得懂 (tīng de dǒng) ฟังเข้าใจได้ | 听不懂 (tīng bù dǒng) ฟังไม่เข้าใจ |
| 看得见 (kàn de jiàn) มองเห็นได้ | 看不见 (kàn bù jiàn) มองไม่เห็น |
| 吃得完 (chī de wán) กินหมดได้ | 吃不完 (chī bù wán) กินไม่หมด |
| 做得到 (zuò de dào) ทำได้ | 做不到 (zuò bù dào) ทำไม่ได้ |
| 写得完 (xiě de wán) เขียนเสร็จได้ | 写不完 (xiě bù wán) เขียนไม่เสร็จ |
| 拿得动 (ná de dòng) ยกได้ | 拿不动 (ná bù dòng) ยกไม่ได้ |
| 走得了 (zǒu de liǎo) เดินได้ | 走不了 (zǒu bù liǎo) เดินไม่ได้ |
| 来得及 (lái de jí) ทันเวลาได้ | 来不及 (lái bù jí) ไม่ทัน |

**ตัวอย่างประโยค:**
1. 老师说的你**听得懂**吗？Lǎoshī shuō de nǐ **tīng de dǒng** ma? → สิ่งที่ครูพูดคุณฟังเข้าใจไหม?
2. 这么多菜你**吃得完**吗？Zhème duō cài nǐ **chī de wán** ma? → อาหารมากขนาดนี้คุณกินหมดได้ไหม?
3. 他**做得到**，别担心。Tā **zuò de dào**, bié dānxīn. → เขาทำได้ ไม่ต้องกังวล
4. 这本书很厚，我**看不完**。Zhè běn shū hěn hòu, wǒ **kàn bù wán**. → หนังสือเล่มนี้หนามาก ฉันอ่านไม่จบ
5. 天太暗了，**看不见**。Tiān tài àn le, **kàn bù jiàn**. → ฟ้ามืดเกินไป มองไม่เห็น
6. 我们**来得及**，别跑！Wǒmen **lái de jí**, bié pǎo! → เรายังทันอยู่ ไม่ต้องวิ่ง!

### 步骤 425: Duration Complement (时量补语)

**时量补语** บอกระยะเวลาของการกระทำ

**โครงสร้าง:**
- ไม่มีกรรม: V + 时间词
- มีกรรม: V + 时间词 + 宾语 หรือ V + 宾语 + V + 时间词

**ตัวอย่างระยะเวลา:**
1. 我学了**三年**汉语。Wǒ xué le **sān nián** Hànyǔ. → ฉันเรียนภาษาจีนมาสามปีแล้ว
2. 他睡了**八个小时**。Tā shuì le **bā gè xiǎoshí**. → เขานอนหลับแปดชั่วโมง
3. 我们等了**半个小时**。Wǒmen děng le **bàn gè xiǎoshí**. → พวกเรารอมาครึ่งชั่วโมงแล้ว
4. 她工作了**十年**了。Tā gōngzuò le **shí nián** le. → เธอทำงานมาสิบปีแล้ว

**กรณีมีกรรม (กริยาซ้ำ):**
1. 他学汉语学了**三年**。Tā xué Hànyǔ xué le **sān nián**. → เขาเรียนภาษาจีนมาสามปีแล้ว
2. 我等他等了**两个小时**。Wǒ děng tā děng le **liǎng gè xiǎoshí**. → ฉันรอเขามาสองชั่วโมงแล้ว

### 步骤 426: Frequency Complement (动量补语)

**动量补语** บอกจำนวนครั้งของการกระทำ

**คำบอกความถี่:**
- 次 (cì) - ครั้ง
- 遍 (biàn) - รอบ (ทำครบทุกขั้นตอน)
- 下 (xià) - ครั้ง (ไม่เป็นทางการ)
- 回 (huí) - รอบ/ครั้ง

**ตัวอย่าง:**
1. 我去过中国**两次**。Wǒ qù guò Zhōngguó **liǎng cì**. → ฉันไปจีนมาสองครั้งแล้ว
2. 请再说**一遍**。Qǐng zài shuō **yī biàn**. → กรุณาพูดซ้ำอีกรอบหนึ่ง
3. 这本书我读了**三遍**。Zhè běn shū wǒ dú le **sān biàn**. → ฉันอ่านหนังสือเล่มนี้ไปสามรอบแล้ว
4. 他打了我**一下**。Tā dǎ le wǒ **yī xià**. → เขาตีฉันครั้งหนึ่ง

### บทสนทนา 1: ใช้ Result Complement

**学生 (Xuéshēng):** 老师，您说的我没听懂，可以再说一遍吗？
Lǎoshī, nín shuō de wǒ méi tīng dǒng, kěyǐ zài shuō yī biàn ma?
คุณครู ที่ครูพูดหนูฟังไม่เข้าใจ กรุณาพูดซ้ำอีกครั้งได้ไหมครับ?

**老师 (Lǎoshī):** 当然可以！你要记住这个语法，练习是非常重要的。
Dāngrán kěyǐ! Nǐ yào jì zhù zhège yǔfǎ, liànxí shì fēicháng zhòngyào de.
แน่นอนเลยค่ะ! หนูต้องจำไวยากรณ์นี้ให้ได้ การฝึกสำคัญมากนะคะ

**学生:** 好的，这次我听懂了！我会把它记住的。
Hǎo de, zhè cì wǒ tīng dǒng le! Wǒ huì bǎ tā jì zhù de.
ได้ครับ คราวนี้ผมเข้าใจแล้ว! ผมจะจำไว้ครับ

**老师:** 很好！你的汉语进步得很快！
Hěn hǎo! Nǐ de Hànyǔ jìnbù de hěn kuài!
ดีมากค่ะ! ภาษาจีนของหนูพัฒนาเร็วมากเลย!

### บทสนทนา 2: ใช้ Directional Complement

**妈妈 (Māma):** 宝贝，把玩具拿上来！
Bǎobèi, bǎ wánjù ná shàng lái!
ลูก เอาของเล่นขึ้นมาด้วยนะ!

**孩子 (Háizi):** 妈妈，我上来了！
Māma, wǒ shàng lái le!
แม่ หนูขึ้นมาแล้ว!

**妈妈:** 好，进来吧，把鞋脱掉。
Hǎo, jìn lái ba, bǎ xié tuō diào.
โอเคนะลูก เดินเข้ามาเลย ถอดรองเท้าด้วยนะ

**孩子:** 好的。妈妈，爸爸几点回来？
Hǎo de. Māma, bàba jǐ diǎn huí lái?
ได้ค่ะ แม่ พ่อจะกลับมากี่โมงคะ?

**妈妈:** 他快回来了！你出去叫他进来吃饭吧！
Tā kuài huí lái le! Nǐ chū qù jiào tā jìn lái chī fàn ba!
เขาจะกลับมาแล้ว ออกไปเรียกพ่อเข้ามากินข้าวด้วยนะ!

### บทสนทนา 3: ใช้ Degree Complement

**朋友A (Péngyǒu A):** 你今天怎么样？
Nǐ jīntiān zěnme yàng?
วันนี้เป็นยังไงบ้าง?

**朋友B (Péngyǒu B):** 今天累死了！工作做不完，老板还要我加班。
Jīntiān lèi sǐ le! Gōngzuò zuò bù wán, lǎobǎn hái yào wǒ jiābān.
วันนี้เหนื่อยตายเลย! งานทำไม่เสร็จ เจ้านายยังให้ทำงานล่วงเวลาอีก

**朋友A:** 真的吗？你跑步跑得这么快，身体这么好，怎么会累呢？
Zhēn de ma? Nǐ pǎobù pǎo de zhème kuài, shēntǐ zhème hǎo, zěnme huì lèi ne?
จริงเหรอ? คุณวิ่งได้เร็วมากขนาดนี้ สุขภาพดีขนาดนี้ จะเหนื่อยได้ยังไงล่ะ?

**朋友B:** 跑步是跑步，工作是工作！今天压力大得不得了！
Pǎobù shì pǎobù, gōngzuò shì gōngzuò! Jīntiān yālì dà de bùdéliǎo!
วิ่งก็เรื่องหนึ่ง ทำงานก็อีกเรื่องหนึ่ง! วันนี้เครียดมากจนไม่ไหวเลย!

---

### บทสนทนา 4: ใช้ Potential Complement

**导演 (Dǎoyǎn):** 你能不能在三天内写完这个剧本？
Nǐ néng bù néng zài sān tiān nèi xiě wán zhège jùběn?
คุณสามารถเขียนบทละครนี้เสร็จภายในสามวันได้ไหม?

**编剧 (Biānjù):** 三天内写不完，可能需要一周。
Sān tiān nèi xiě bù wán, kěnéng xūyào yī zhōu.
สามวันเขียนไม่เสร็จหรอก น่าจะต้องใช้เวลาหนึ่งสัปดาห์ครับ

**导演:** 一周？这么慢？你每天写得完多少页？
Yī zhōu? Zhème màn? Nǐ měitiān xiě de wán duōshǎo yè?
หนึ่งสัปดาห์เหรอ? ช้าขนาดนั้น? แต่ละวันคุณเขียนได้กี่หน้า?

**编剧:** 每天大概写得完十页。您看得懂我的手稿吗？
Měitiān dàgài xiě de wán shí yè. Nín kàn de dǒng wǒ de shǒugǎo ma?
แต่ละวันเขียนได้ประมาณสิบหน้าครับ คุณอ่านต้นฉบับมือของผมเข้าใจไหมครับ?

**导演:** 看得懂，你写得很清楚。好，就一周吧！
Kàn de dǒng, nǐ xiě de hěn qīngchǔ. Hǎo, jiù yī zhōu ba!
อ่านเข้าใจได้ คุณเขียนได้ชัดเจนมาก โอเค ก็หนึ่งสัปดาห์ก็ได้!

## 🔊 ประโยคฝึกออกเสียง

### ชุดที่ 1: Result Complement
1. 作业写完了吗？Zuòyè xiě wán le ma? → ทำการบ้านเสร็จแล้วไหม?
2. 我找到钥匙了！Wǒ zhǎo dào yàoshi le! → ฉันหากุญแจเจอแล้ว!
3. 他没听懂老师的解释。Tā méi tīng dǒng lǎoshī de jiěshì. → เขาฟังคำอธิบายของครูไม่เข้าใจ
4. 这个单词你记住了吗？Zhège dāncí nǐ jì zhù le ma? → คำศัพท์นี้คุณจำได้แล้วไหม?
5. 我做完了所有的事。Wǒ zuò wán le suǒyǒu de shì. → ฉันทำทุกอย่างเสร็จแล้ว
6. 你看见他了吗？Nǐ kàn jiàn tā le ma? → คุณเห็นเขาแล้วหรือยัง?
7. 他没买到火车票。Tā méi mǎi dào huǒchē piào. → เขาซื้อตั๋วรถไฟไม่ได้
8. 她学会了游泳。Tā xué huì le yóuyǒng. → เธอเรียนว่ายน้ำจนทำได้แล้ว
9. 我没听清楚你说什么。Wǒ méi tīng qīngchǔ nǐ shuō shénme. → ฉันฟังไม่ชัดว่าคุณพูดอะไร
10. 房间打扫好了。Fángjiān dǎsǎo hǎo le. → ห้องทำความสะอาดเรียบร้อยแล้ว

### ชุดที่ 2: Directional Complement
11. 请走进来！Qǐng zǒu jìn lái! → กรุณาเดินเข้ามา!
12. 他从楼上跑下来了。Tā cóng lóu shàng pǎo xià lái le. → เขาวิ่งลงมาจากชั้นบนแล้ว
13. 请把东西拿进来。Qǐng bǎ dōngxi ná jìn lái. → กรุณาหยิบของเข้ามา
14. 她走出去了。Tā zǒu chū qù le. → เธอเดินออกไปแล้ว
15. 孩子们从外面跑进来了。Háizimen cóng wàimiàn pǎo jìn lái le. → เด็กๆ วิ่งเข้ามาจากข้างนอกแล้ว

### ชุดที่ 3: Degree Complement
16. 他英语说得很好。Tā Yīngyǔ shuō de hěn hǎo. → เขาพูดภาษาอังกฤษได้ดีมาก
17. 她跑得比我快多了。Tā pǎo de bǐ wǒ kuài duō le. → เธอวิ่งได้เร็วกว่าฉันมาก
18. 今天高兴死了！Jīntiān gāoxìng sǐ le! → วันนี้ดีใจมากตายเลย!
19. 这个电影好看极了！Zhège diànyǐng hǎo kàn jí le! → หนังเรื่องนี้ดูดีมากที่สุดเลย!
20. 他写汉字写得很漂亮。Tā xiě Hànzì xiě de hěn piàoliang. → เขาเขียนอักษรจีนได้สวยมาก

### ชุดที่ 4: Potential Complement
21. 这个字你认得出来吗？Zhège zì nǐ rèn de chū lái ma? → ตัวอักษรนี้คุณจำได้ไหม?
22. 这么远，你走得到吗？Zhème yuǎn, nǐ zǒu de dào ma? → ไกลขนาดนี้ คุณเดินไปถึงได้ไหม?
23. 三个小时能写得完吗？Sān gè xiǎoshí néng xiě de wán ma? → สามชั่วโมงเขียนเสร็จได้ไหม?
24. 这么重的东西他拿不动。Zhème zhòng de dōngxi tā ná bù dòng. → ของหนักขนาดนี้เขายกไม่ได้
25. 来得及来得及，别担心！Lái de jí lái de jí, bié dānxīn! → ทันทัน ไม่ต้องกังวล!

## ✏️ แบบฝึกหัด

### แบบฝึกหัด 1: เติม Result Complement

**คำสั่ง:** เลือก RC ที่ถูกต้อง (完/懂/到/见/住/好/会)

1. 这本书我看___了。(อ่านเข้าใจแล้ว)
2. 我找___钥匙了。(หากุญแจเจอแล้ว)
3. 作业写___了吗？(ทำการบ้านเสร็จแล้วไหม?)
4. 这个单词你记___了吗？(จำคำศัพท์นี้ได้แล้วไหม?)
5. 他没有听___老师说的。(ฟังสิ่งที่ครูพูดไม่เข้าใจ)
6. 他___了游泳。(เรียนว่ายน้ำจนทำได้แล้ว)
7. 你看___那个人了吗？(คุณเห็นคนนั้นแล้วไหม?)
8. 准备___了吗？(เตรียมพร้อมแล้วหรือยัง?)

**เฉลย:** 1.懂 2.到 3.完 4.住 5.懂 6.学会 7.见 8.好

### แบบฝึกหัด 2: แปลเป็นภาษาจีนโดยใช้ Potential Complement

1. ฉันกินไม่หมด (อาหารมากเกินไป) → ___
2. ฉันเข้าใจภาษาจีน → ___
3. เขาอ่านหนังสือนี้ไม่จบ (หนาเกินไป) → ___
4. เธอเดินไปไม่ถึง (ไกลเกินไป) → ___
5. คุณทำสิ่งนี้ได้ไหม? → ___
6. เราทันเวลา → ___
7. ของหนักเกินไป ยกไม่ได้ → ___
8. คุณฟังเข้าใจไหม? → ___

**เฉลย:**
1. 我吃不完
2. 我听得懂中文
3. 他看不完这本书
4. 她走不到
5. 你做得到这件事吗？
6. 我们来得及
7. 东西太重，拿不动
8. 你听得懂吗？

### แบบฝึกหัด 3: เปลี่ยนประโยคปฏิเสธ

1. 我听懂了。→ (ไม่เข้าใจ) ___
2. 他找到了工作。→ (หาไม่ได้) ___
3. 她记住了名字。→ (จำไม่ได้) ___
4. 我们来得及。→ (ไม่ทัน) ___
5. 他拿得动。→ (ยกไม่ได้) ___

**เฉลย:**
1. 我没听懂。/ 我听不懂。
2. 他没找到工作。/ 他找不到工作。
3. 她没记住名字。/ 她记不住名字。
4. 我们来不及。
5. 他拿不动。

### แบบฝึกหัด 4: สร้างประโยคด้วย Degree Complement

**คำสั่ง:** ใช้คำที่กำหนดสร้างประโยค

1. 唱歌/好 → (เธอร้องเพลงได้ดีมาก)
2. 天气/热/死了 → (อากาศร้อนมากตาย)
3. 写汉字/漂亮 → (เขาเขียนอักษรจีนได้สวยมาก)
4. 做菜/好吃 → (แม่ทำอาหารได้อร่อยมาก)
5. 跑步/快 → (เขาวิ่งได้เร็วมาก)

### แบบฝึกหัด 5: ฝึกสนทนา

สถานการณ์: คุณกลับมาจากการช็อปปิ้ง ใช้ Complement ต่อไปนี้:
- หาของที่ต้องการเจอ (找到)
- ซื้อเสื้อตัวที่ชอบได้ (买到)
- น้ำหนักของมากจนยกไม่ค่อยได้ (拿不动)
- เดินนานมาก เหนื่อยตาย (累死了)

## 📖 สรุปประจำ Part 043

### สรุป Complement Structures

| ประเภท | โครงสร้าง | ความหมาย |
|-------|---------|---------|
| Result (结果) | V + RC | ผลลัพธ์ของการกระทำ |
| Directional (趋向) | V + Direction | ทิศทางการเคลื่อนที่ |
| Degree (程度) | V + 得 + Degree | ระดับความเข้มข้น |
| Potential (可能) | V + 得/不 + RC | ทำได้/ทำไม่ได้ |
| Duration (时量) | V + Time | ระยะเวลา |
| Frequency (动量) | V + Times | จำนวนครั้ง |

### Result Complements ที่ต้องจำ:
完(wán), 好(hǎo), 到(dào), 懂(dǒng), 见(jiàn), 住(zhù), 会(huì), 清楚(qīngchǔ)

### Directional Complements ที่ต้องจำ:
上来/下去/进来/出去/回来/过来/起来
