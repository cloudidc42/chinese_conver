1. เขียนอีเมลภาษาจีนทั้งแบบทางการและไม่ทางการ

```
2. 型号ABC-200：数量300个

感谢您的关注与支持！

此致
敬礼

Somchai Jitrakul
采购经理
泰国ABC贸易公司
电话：+66-xx-xxxx-xxxx
邮箱：somchai@abctrade.co.th
```

**แปล:**
```
หัวข้อ: สอบถามราคาสินค้าของบริษัทท่าน
```

## 💬 การสื่อสารผ่าน WeChat และ SMS

### 步骤 465: ข้อความ WeChat ทั่วไป

**ข้อความสั้นๆ ที่ใช้บ่อย:**

| ข้อความ | Pinyin | ความหมาย |
|--------|--------|---------|

| 在的！ | Zài de! | อยู่นะ! |
| 收到了！ | Shōu dào le! | ได้รับแล้ว! |
| 好的！ | Hǎo de! | โอเค! |
| 没问题！ | Méi wèntí! | ไม่มีปัญหา! |
| 一会儿见！ | Yī huìr jiàn! | เดี๋ยวเจอกัน! |
| 晚点说！ | Wǎn diǎn shuō! | คุยทีหลังนะ! |
| 忙吗？ | Máng ma? | ยุ่งอยู่ไหม? |
| 好久不见！ | Hǎo jiǔ bú jiàn! | ไม่ได้เจอกันนาน! |
| 辛苦了！ | Xīnkǔ le! | เหนื่อยมากนะ! / ขอบคุณที่เหนื่อย |

```
Méi wèntí! Dào le gàosu wǒ. 👍
```

**小李 (Xiǎo Lǐ):** 发了，刚发过去。我抄送你了，你去收件箱看看。

19. 我在群里回复你了，你去看看。(Wǒ zài qún lǐ huífù nǐ le, nǐ qù kàn kàn.) → ฉันตอบในกลุ่มแล้ว ไปดูนะ
20. 语音消息我不方便听，可以发文字吗？(Yǔyīn xiāoxi wǒ bù fāngbiàn tīng, kěyǐ fā wénzì ma?) → ไม่สะดวกฟังข้อความเสียง ส่งเป็นตัวอักษรได้ไหม?

### แบบฝึกหัด 5: จัดเรียงส่วนประกอบอีเมล

จัดเรียงส่วนประกอบต่อไปนี้ให้เป็นอีเมลทางการที่ถูกต้อง:

ก. 此致 敬礼
ข. 期待您的回复，谢谢！
ค. 尊敬的李总经理：
ง. 我是泰国XYZ公司的销售经理Somchai。
จ. 如有问题，请随时与我联系。
ฉ. 随函附上我们公司的产品目录，请查阅。
ช. 您好！

**เฉลย (ลำดับที่ถูกต้อง):** ค → ช → ง → ฉ → จ → ข → ก

---

### แบบฝึกหัด 6: สถานการณ์จำลอง — เขียนอีเมลสั้น

เขียนอีเมลภาษาจีนตามสถานการณ์ (5-6 ประโยค):

**สถานการณ์:** คุณต้องการยกเลิกการนัดหมายประชุมในวันพรุ่งนี้เวลา 10.00 น. เนื่องจากมีธุระเร่งด่วน และขอนัดใหม่ในวันถัดไป

**โครงสร้างที่แนะนำ:**
- คำขึ้นต้น: 您好！
- แจ้งเหตุผล: 非常抱歉，由于...
- ขอยกเลิก: 我需要取消明天...的会议
- ขอนัดใหม่: 是否可以改到...？
- ขอโทษ: 给您带来不便，深感抱歉。
- ลงท้าย: 期待您的回复。祝好！

**ตัวอย่างเฉลย:**
```
您好！

非常抱歉，由于临时有紧急事务，我需要取消明天上午十点的会议。
是否可以改到后天同一时间？如您时间不合适，请告知您方便的时间。

给您带来不便，深感抱歉。

期待您的回复。
祝好！
[您的名字]
```

## 📖 สรุปประจำ Part 047

### รูปแบบอีเมลที่ต้องจำ:

**ทางการ:**
- ขึ้นต้น: 尊敬的...先生/女士：
- ลงท้าย: 此致 敬礼

**กึ่งทางการ:**
- ขึ้นต้น: 您好！
- ลงท้าย: 祝好 / 谢谢！

**ไม่ทางการ:**
- ขึ้นต้น: 嗨！/ 你好！
- ลงท้าย: 拜拜！

### วลีอีเมลสำคัญ:
- 请查收 (qǐng chá shōu) - กรุณาตรวจสอบ
- 如有问题请告知 (rú yǒu wèntí qǐng gàozhī) - หากมีคำถามกรุณาแจ้ง
- 期待您的回复 (qīdài nín de huífù) - รอคำตอบกลับ
- 不胜感谢 (bù shèng gǎnxiè) - ขอบคุณอย่างสุดซึ้ง
