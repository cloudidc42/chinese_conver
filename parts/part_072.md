## 📝 โครงสร้างและวลีสำคัญ

### วลีในการประชุมเทคนิค:
- 这批产品的合格率是多少？(Zhè pī chǎnpǐn de hégé lǜ shì duōshao?) — อัตราผ่านมาตรฐานของล็อตนี้เท่าไหร่?
- 不良率超过了我们的目标值。(Bùliáng lǜ chāoguò le wǒmen de mùbiāo zhí.) — อัตราของเสียเกินกว่าค่าเป้าหมายของเรา
- 我们需要分析根本原因。(Wǒmen xūyào fēnxī gēnběn yuányīn.) — เราต้องวิเคราะห์สาเหตุหลัก
- 请提供FMEA分析报告。(Qǐng tígōng FMEA fēnxī bàogào.) — กรุณาจัดทำรายงานการวิเคราะห์ FMEA
- 这个问题需要立即纠正措施。(Zhège wèntí xūyào lìjí jiūzhèng cuòshī.) — ปัญหานี้ต้องการมาตรการแก้ไขทันที

### วลีในโรงงาน:
- 这台设备需要定期维护保养。(Zhè tái shèbèi xūyào dìngqī wéihù bǎoyǎng.) — เครื่องนี้ต้องบำรุงรักษาสม่ำเสมอ
- 生产线停机了，原因是什么？(Shēngchǎn xiàn tíng jī le, yuányīn shì shénme?) — สายการผลิตหยุดทำงาน สาเหตุคืออะไร?
- 按照SOP操作，不要走捷径。(Àn zhào SOP cāozuò, bùyào zǒu jiéjìng.) — ปฏิบัติตาม SOP อย่าลัดขั้นตอน
- 这个公差是±0.05mm。(Zhège gōngchā shì ±0.05mm.) — ค่าพิกัดความเผื่อคือ ±0.05mm

## 💬 บทสนทนาวิชาชีพ

### บทสนทนาที่ 1: การประชุมการผลิต (Production Meeting)

**ผู้จัดการโรงงาน:** 大家好，今天产线运行情况怎么样？产量达到目标了吗？
(Dàjiā hǎo, jīntiān chǎn xiàn yùnxíng qíngkuàng zěnmeyàng? Chǎnliàng dádào mùbiāo le ma?)
สวัสดีทุกคน วันนี้สายการผลิตเป็นอย่างไรบ้าง? ผลผลิตถึงเป้าหมายไหม?

**หัวหน้าผลิต:** 报告张总，今天完成了1,850件，目标是2,000件，完成率92.5%。主要是下午三点到五点，3号机台出现了液压系统故障，停机两小时。
(Bàogào Zhāng zǒng, jīntiān wánchéng le 1,850 jiàn, mùbiāo shì 2,000 jiàn, wánchéng lǜ 92.5%. Zhǔyào shì xiàwǔ sān diǎn dào wǔ diǎn, 3 hào jī tái chūxiàn le yèyā xìtǒng gùzhàng, tíng jī liǎng xiǎoshí.)
รายงานคุณจาง วันนี้ผลิตได้ 1,850 ชิ้น เป้าหมาย 2,000 ชิ้น อัตราการทำงาน 92.5% ส่วนใหญ่เพราะบ่ายสามถึงห้าโมง เครื่องจักรหมายเลข 3 มีปัญหาระบบไฮดรอลิก หยุดเครื่องสองชั่วโมง

**ผู้จัดการ:** 维修工程师在哪里？液压故障是什么原因？
(Wéixiū gōngchéngshī zài nǎlǐ? Yèyā gùzhàng shì shénme yuányīn?)
วิศวกรซ่อมบำรุงอยู่ไหน? สาเหตุของปัญหาไฮดรอลิกคืออะไร?

**วิศวกร:** 是液压油泄漏，密封圈磨损导致的。我们已经更换了密封件，机台恢复运行了。建议每月检查液压油位和密封圈状态。
(Shì yèyā yóu xìlòu, mìfēng quān mósǔn dǎozhì de. Wǒmen yǐjīng gēnghuàn le mìfēng jiàn, jī tái huīfù yùnxíng le. Jiànyì měi yuè jiǎnchá yèyā yóu wèi hé mìfēng quān zhuàngtài.)
เป็นน้ำมันไฮดรอลิกรั่ว เกิดจากแหวนยางซีลเสียหาย เราเปลี่ยนชิ้นส่วนซีลแล้ว เครื่องกลับมาทำงานได้แล้ว แนะนำให้ตรวจสอบระดับน้ำมันไฮดรอลิกและสภาพแหวนยางซีลทุกเดือน

**ผู้จัดการ:** 好，这个要写进预防性维护计划里。明天计划怎么安排补产？
(Hǎo, zhège yào xiě jìn yùfángxìng wéihù jìhuà lǐ. Míngtiān jìhuà zěnme ānpái bǔ chǎn?)
ดี เรื่องนี้ต้องเขียนลงในแผนการบำรุงรักษาเชิงป้องกัน พรุ่งนี้วางแผนผลิตชดเชยอย่างไร?

**หัวหน้าผลิต:** 明天安排加班两小时，预计可以补回150件的缺口。
(Míngtiān ānpái jiābān liǎng xiǎoshí, yùjì kěyǐ bǔ huí 150 jiàn de quēkǒu.)
พรุ่งนี้จัดทำงานล่วงเวลาสองชั่วโมง คาดว่าจะชดเชยยอด 150 ชิ้นที่ขาดได้

### บทสนทนาที่ 2: การตรวจสอบคุณภาพ (Quality Inspection)

**QC Inspector:** 这批零件我检查了100件，发现有8件尺寸超差，主要是外径超出规格范围。
(Zhè pī língjiàn wǒ jiǎnchá le 100 jiàn, fāxiàn yǒu 8 jiàn chǐcùn chāo chā, zhǔyào shì wàijìng chāochū guīgé fànwéi.)
ล็อตชิ้นส่วนนี้ผมตรวจ 100 ชิ้น พบว่า 8 ชิ้นมีขนาดเกินพิกัดความเผื่อ ส่วนใหญ่เป็นเส้นผ่านศูนย์กลางภายนอกเกินช่วงที่กำหนด

**วิศวกรกระบวนการ:** 超差量是多少？有多少在公差上限以上？
(Chāo chā liàng shì duōshao? Yǒu duōshao zài gōngchā shànghàn yǐshàng?)
ค่าที่เกินพิกัดมากแค่ไหน? มีกี่ชิ้นที่เกินค่าพิกัดบน?

**QC Inspector:** 最大超差是0.03mm，规格是25±0.02mm，所以最大值达到了25.05mm。8件都超过上限。这批需要全部返工。
(Zuìdà chāo chā shì 0.03mm, guīgé shì 25±0.02mm, suǒyǐ zuìdà zhí dádào le 25.05mm. 8 jiàn dōu chāoguò shànghàn. Zhè pī xūyào quánbù fǎngōng.)
ค่าที่เกินมากสุดคือ 0.03mm สเปคคือ 25±0.02mm ดังนั้นค่าสูงสุดถึง 25.05mm ทั้ง 8 ชิ้นเกินค่าพิกัดบนหมด ล็อตนี้ต้องแก้ไขงานทั้งหมด

**วิศวกรกระบวนการ:** 我要查一下CNC程序和刀具磨损情况。可能是刀具磨损导致的尺寸漂移。
(Wǒ yào chá yīxià CNC chéngxù hé dāojù mósǔn qíngkuàng. Kěnéng shì dāojù mósǔn dǎozhì de chǐcùn piāoyí.)
ผมต้องตรวจโปรแกรม CNC และสภาพการสึกหรอของเครื่องมือ อาจเป็นการสึกหรอของเครื่องมือทำให้ขนาดเคลื่อน

### บทสนทนาที่ 3: การประชุม IT/Software

**ผู้จัดการ IT:** 这次系统升级遇到了什么问题？
(Zhè cì xìtǒng shēngjí yùdào le shénme wèntí?)
การอัพเกรดระบบครั้งนี้เจอปัญหาอะไรบ้าง?

**วิศวกร Software:** 主要有两个问题。第一，新版本与旧版数据库存在兼容性问题，导致部分数据迁移失败。第二，API接口调用出现了延迟，响应时间从200ms增加到了800ms。
(Zhǔyào yǒu liǎng gè wèntí. Dì yī, xīn bǎnběn yǔ jiù bǎn shùjùkù cúnzài jiānróngxìng wèntí, dǎozhì bùfèn shùjù qiānyí shībài. Dì èr, API jiēkǒu diàoyòng chūxiàn le yánchí, xiǎngyīng shíjiān cóng 200ms zēngjiā dào le 800ms.)
มีปัญหาหลักสองอย่าง อย่างแรก เวอร์ชั่นใหม่มีปัญหาความเข้ากันได้กับฐานข้อมูลเก่า ทำให้การย้ายข้อมูลบางส่วนล้มเหลว อย่างที่สอง การเรียก API interface มีความล่าช้า เวลาตอบสนองเพิ่มจาก 200ms เป็น 800ms

**ผู้จัดการ IT:** 数据迁移的问题解决了吗？API延迟的原因找到了吗？
(Shùjù qiānyí de wèntí jiějué le ma? API yánchí de yuányīn zhǎodào le ma?)
ปัญหาการย้ายข้อมูลแก้ไขได้แล้วหรือยัง? หาสาเหตุความล่าช้าของ API ได้หรือยัง?

**วิศวกร Software:** 数据库迁移问题已经通过编写迁移脚本解决了，成功率99.8%。API延迟我们排查后发现是新版本的数据库查询没有使用索引，导致全表扫描。优化SQL查询后，响应时间恢复到了180ms。
(Shùjùkù qiānyí wèntí yǐjīng tōngguò biānxiě qiānyí jiǎoběn jiějué le, chénggōng lǜ 99.8%. API yánchí wǒmen páichá hòu fāxiàn shì xīn bǎnběn de shùjùkù cháxún méiyǒu shǐyòng suǒyǐn, dǎozhì quán biǎo sǎomiáo. Yōuhuà SQL cháxún hòu, xiǎngyīng shíjiān huīfù dào le 180ms.)
ปัญหาการย้ายฐานข้อมูลแก้ไขแล้วโดยการเขียน migration script อัตราสำเร็จ 99.8% ความล่าช้าของ API หลังตรวจสอบพบว่าการ query ฐานข้อมูลเวอร์ชั่นใหม่ไม่ได้ใช้ index ทำให้ scan ทั้งตาราง หลังจาก optimize SQL query แล้ว เวลาตอบสนองกลับมาที่ 180ms

### บทสนทนาที่ 4: ความปลอดภัยในโรงงาน (Factory Safety)

**หัวหน้างานความปลอดภัย:** 各位同事，我们来进行今天的安全生产会议。上周发生了一起轻伤事故，有人在操作冲压机时手指被夹伤。

เพื่อนร่วมงานทุกคน มาเริ่มการประชุมความปลอดภัยในการผลิตวันนี้กัน สัปดาห์ที่แล้วเกิดอุบัติเหตุเล็กน้อย มีคนนิ้วถูกหนีบตอนใช้งานเครื่องปั๊ม

**พนักงาน:** 那个同事现在怎么样了？
(Nà gè tóngshì xiànzài zěnmeyàng le?)
เพื่อนร่วมงานคนนั้นเป็นอย่างไรบ้างตอนนี้?

**หัวหน้างาน:** 伤情不严重，已经康复上班了。但这件事给我们敲了警钟。操作冲压机必须严格遵守双手操作规定，两手必须同时按下启动按钮才能动作。绝对不能将手伸入模具范围内。
(Shāngqíng bù yánzhòng, yǐjīng kāngfù shàngbān le. Dàn zhè jiàn shì gěi wǒmen qiāo le jǐngzhōng. Cāozuò chōngyā jī bìxū yángé zūnshǒu shuāngshǒu cāozuò guīdìng, liǎng shǒu bìxū tóngshí àn xià qǐdòng ànniǔ cái néng dòngzuò. Juéduì bù néng jiāng shǒu shēn rù mójù fànwéi nèi.)
อาการบาดเจ็บไม่รุนแรง กลับมาทำงานได้แล้ว แต่เรื่องนี้เป็นการเตือนใจพวกเรา การใช้งานเครื่องปั๊มต้องปฏิบัติตามกฎการใช้สองมืออย่างเคร่งครัด ต้องกดปุ่มสตาร์ทพร้อมกันทั้งสองมือจึงจะทำงาน ห้ามสอดมือเข้าไปในบริเวณแม่พิมพ์เด็ดขาด

### บทสนทนาที่ 5: การประเมินซัพพลายเออร์ (Supplier Evaluation)

(Gǎnxiè guì gōngsī de xìnrèn. Qǐngwèn jīnnián de pínggū jiéguǒ rúhé?)
ขอบคุณที่บริษัทของท่านไว้วางใจ ขอถามว่าผลการประเมินปีนี้เป็นอย่างไร?

ด้านคุณภาพ อัตราของเสียในวัตถุดิบรับเข้าคือ 0.8% เป้าหมายคือภายใน 1% ผลงานดี อัตราส่งมอบตรงเวลาคือ 94% เป้าหมายคือ 95% ต่ำกว่าเป้าหมายเล็กน้อย คะแนนความสามารถในการแข่งขันด้านราคาคือ B+ คะแนนรวม 89 คะแนน ประเมินผลรวมดี ยังคงสถานะซัพพลายเออร์ที่ผ่านมาตรฐาน

### บทสนทนาที่ 6: การประชุม Agile Sprint

### บทสนทนาที่ 8: Troubleshooting เครื่องจักร

**ช่างซ่อม:** 这台注塑机报警了，显示屏显示"料筒温度异常"。
(Zhè tái zhùsù jī bào jǐng le, xiǎnshì píng xiǎnshì "liào tǒng wēndù yìcháng".)
เครื่องฉีดพลาสติกเครื่องนี้แจ้งเตือน หน้าจอแสดง "อุณหภูมิกระบอกวัตถุดิบผิดปกติ"

**วิศวกร:** 检查一下加热圈和温度传感器。先看第几段的温度显示异常？
(Jiǎnchá yīxià jiārè quān hé wēndù chuángǎnqì. Xiān kàn dì jǐ duàn de wēndù xiǎnshì yìcháng?)
ตรวจสอบขดลวดทำความร้อนและเซ็นเซอร์วัดอุณหภูมิ ดูก่อนว่าส่วนที่เท่าไหร่ที่แสดงอุณหภูมิผิดปกติ?

**ช่างซ่อม:** 第3段显示温度只有180°C，设定值是240°C，差了60度。其他段都正常。
(Dì 3 duàn xiǎnshì wēndù zhǐ yǒu 180°C, shèdìng zhí shì 240°C, chā le 60 dù. Qítā duàn dōu zhèngcháng.)
ส่วนที่ 3 แสดงอุณหภูมิแค่ 180°C ค่าตั้งคือ 240°C ต่างกัน 60 องศา ส่วนอื่นๆ ปกติหมด

**วิศวกร:** 很可能是加热圈断了或者温度传感器故障。用万用表测量加热圈的电阻值，正常应该是45-55欧姆。如果断路就换新的加热圈，如果电阻正常就换传感器。
(Hěn kěnéng shì jiārè quān duàn le huòzhě wēndù chuángǎnqì gùzhàng. Yòng wànyòng biǎo cèliáng jiārè quān de diànzǔ zhí, zhèngcháng yīnggāi shì 45-55 ōumǔ. Rúguǒ duànlù jiù huàn xīn de jiārè quān, rúguǒ diànzǔ zhèngcháng jiù huàn chuángǎnqì.)
น่าจะเป็นขดลวดทำความร้อนขาด หรือเซ็นเซอร์วัดอุณหภูมิเสีย ใช้มัลติมิเตอร์วัดค่าความต้านทานของขดลวด ค่าปกติควรอยู่ที่ 45-55 โอห์ม ถ้าวงจรขาดให้เปลี่ยนขดลวดใหม่ ถ้าความต้านทานปกติให้เปลี่ยนเซ็นเซอร์

### บทสนทนาที่ 9: การวางแผนโครงการ (Project Planning)

**ผู้จัดการโครงการ:** 我们的新产品开发项目计划用8个月完成。我画了甘特图，让我来介绍一下主要里程碑。
(Wǒmen de xīn chǎnpǐn kāifā xiàngmù jìhuà yòng 8 gè yuè wánchéng. Wǒ huà le gǎntè tú, ràng wǒ lái jièshào yīxià zhǔyào lǐchéngbēi.)
โครงการพัฒนาผลิตภัณฑ์ใหม่ของเราวางแผนเสร็จใน 8 เดือน ผมวาดแผนภูมิ Gantt มาแล้ว ให้ผมแนะนำ milestone สำคัญ

**ทีมงาน:** 关键路径在哪里？有没有风险较高的环节？
(Guānjiàn lùjìng zài nǎlǐ? Yǒu méiyǒu fēngxiǎn jiào gāo de huánjié?)
Critical Path อยู่ที่ไหน? มีขั้นตอนที่เสี่ยงสูงไหม?

**ผู้จัดการโครงการ:** 关键路径是：需求分析→设计→模具制造→试模→验证→量产准备。其中模具制造是风险最高的环节，供应商反馈交期需要10周，而我们计划是8周。我建议同时联系备用供应商，做好风险预案。
(Guānjiàn lùjìng shì: xūqiú fēnxī→shèjì→mójù zhìzào→shì mó→yànzhèng→liàngchǎn zhǔnbèi. Qízhōng mójù zhìzào shì fēngxiǎn zuì gāo de huánjié, gōngyìng shāng fǎnkuì jiāo qī xūyào 10 zhōu, ér wǒmen jìhuà shì 8 zhōu. Wǒ jiànyì tóngshí liánxì bèiyòng gōngyìng shāng, zuò hǎo fēngxiǎn yù'àn.)
Critical Path คือ: วิเคราะห์ความต้องการ→ออกแบบ→ผลิตแม่พิมพ์→ทดลองแม่พิมพ์→ตรวจสอบ→เตรียมผลิตจำนวนมาก ในนั้น การผลิตแม่พิมพ์เสี่ยงสูงสุด ซัพพลายเออร์แจ้งว่าต้องการ 10 สัปดาห์ แต่เราวางแผนไว้ 8 สัปดาห์ ผมแนะนำให้ติดต่อซัพพลายเออร์สำรองพร้อมกัน และจัดทำแผนรองรับความเสี่ยง

### บทสนทนาที่ 10: การรายงาน KPI โรงงาน

**หัวหน้าผลิต:** 本月生产KPI汇报。产量完成率98.5%，质量合格率99.2%，OEE整体设备效率达到了82%，设备故障停机时间为4.5小时。

รายงาน KPI การผลิตเดือนนี้ อัตราบรรลุยอดผลิต 98.5% อัตราผ่านมาตรฐานคุณภาพ 99.2% ค่า OEE (Overall Equipment Effectiveness) อยู่ที่ 82% เวลาหยุดเครื่องจากเครื่องเสียรวม 4.5 ชั่วโมง

**ผู้อำนวยการโรงงาน:** OEE目标是85%，差了3个百分点。主要是哪方面拉低了OEE？
(OEE mùbiāo shì 85%, chā le 3 gè bǎifēn diǎn. Zhǔyào shì nǎ fāngmiàn lā dī le OEE?)
เป้าหมาย OEE คือ 85% ยังขาดอีก 3 เปอร์เซ็นต์ ส่วนใหญ่เป็นด้านใดที่ดึง OEE ลง?

**หัวหน้าผลิต:** 主要是换线时间较长，平均换线时间是45分钟，目标是30分钟以内。我们正在推行SMED（快速换模）项目，预计下月可以改善到35分钟以内。
(Zhǔyào shì huàn xiàn shíjiān jiào cháng, píngjūn huàn xiàn shíjiān shì 45 fēnzhōng, mùbiāo shì 30 fēnzhōng yǐnèi. Wǒmen zhèngzài tuīxíng SMED (kuàisù huàn mó) xiàngmù, yùjì xià yuè kěyǐ gǎishàn dào 35 fēnzhōng yǐnèi.)
ส่วนใหญ่เป็นเพราะเวลาเปลี่ยนสายการผลิตนานเกินไป เวลาเปลี่ยนสายเฉลี่ย 45 นาที เป้าหมายคือต่ำกว่า 30 นาที เรากำลังดำเนินโครงการ SMED (Single Minute Exchange of Die) อยู่ คาดว่าเดือนหน้าจะปรับปรุงให้ต่ำกว่า 35 นาทีได้

## 🔊 ประโยคฝึกออกเสียง

1. 这批产品的合格率是多少？(Zhè pī chǎnpǐn de hégé lǜ shì duōshao?) — อัตราผ่านมาตรฐานของล็อตนี้เท่าไหร่?
2. 我们需要分析根本原因并制定纠正措施。(Wǒmen xūyào fēnxī gēnběn yuányīn bìng zhìdìng jiūzhèng cuòshī.) — เราต้องวิเคราะห์สาเหตุหลักและกำหนดมาตรการแก้ไข
3. 设备需要定期维护保养才能保证稳定运行。(Shèbèi xūyào dìngqī wéihù bǎoyǎng cái néng bǎozhèng wěndìng yùnxíng.) — อุปกรณ์ต้องบำรุงรักษาสม่ำเสมอจึงจะทำงานได้อย่างมีเสถียรภาพ
4. 请提供完整的测试报告和验收文件。(Qǐng tígōng wánzhěng de cèshì bàogào hé yànshōu wénjiàn.) — กรุณาจัดทำรายงานการทดสอบและเอกสารรับมอบงานที่ครบถ้วน
5. 这个项目的关键路径是什么？(Zhège xiàngmù de guānjiàn lùjìng shì shénme?) — Critical Path ของโครงการนี้คืออะไร?

## 🏮 วัฒนธรรมวิศวกรรมจีน

**5S ในโรงงานจีน (五常法 Wǔ cháng fǎ):**
1. 整理 (Zhěnglǐ) — SEIRI: แยกสิ่งที่จำเป็นออกจากไม่จำเป็น
2. 整顿 (Zhěngdùn) — SEITON: จัดวางสิ่งของให้เป็นระเบียบ
3. 清扫 (Qīngsǎo) — SEISO: ทำความสะอาด
4. 清洁 (Qīngjié) — SEIKETSU: รักษาความสะอาด
5. 素养 (Sùyǎng) — SHITSUKE: วินัย ปฏิบัติตามกฎ

**แนวคิด "Made in China 2025" (中国制造2025):**
เป็นนโยบายอุตสาหกรรมที่รัฐบาลจีนผลักดันให้ยกระดับการผลิตสู่เทคโนโลยีขั้นสูง เน้น:
- 智能制造 (Zhìnéng zhìzào) — Smart Manufacturing
- 工业互联网 (Gōngyè hùliánwǎng) — Industrial Internet
- 绿色制造 (Lǜsè zhìzào) — Green Manufacturing
