## 🎯 วัตถุประสงค์การเรียนรู้

เมื่อเรียนจบ Part นี้ ผู้เรียนจะสามารถ:
1. อ่านและทำความเข้าใจสัญญาธุรกิจจีนพื้นฐานได้

4. เข้าใจระบบกฎหมายสัญญาและการยุติข้อพิพาทของจีน

## 📝 โครงสร้างสัญญาธุรกิจจีนและภาษาสัญญา

### Step 811: โครงสร้างสัญญาจีนมาตรฐาน (合同结构 Hétong Jiégòu)

สัญญาธุรกิจจีนโดยทั่วไปมีโครงสร้างดังนี้:

#### 1. 合同头部 (Hétong Tóubù) - ส่วนหัวสัญญา
```
买卖合同
(Mǎimài Hétong)
สัญญาซื้อขาย

合同编号：__________
(Hétong biānhào: __________)
เลขที่สัญญา: __________

签订日期：____年____月____日
(Qiāndìng rìqī: ____ nián ____ yuè ____ rì)
วันที่ลงนาม: ปี ___ เดือน ___ วัน ___

签订地点：__________
(Qiāndìng dìdiǎn: __________)
สถานที่ลงนาม: __________
```

#### 2. 当事人信息 (Dāngshì Rén Xìnxī) - ข้อมูลคู่สัญญา
```
甲方（买方）：__________
(Jiǎ fāng (Mǎi fāng): __________)
ฝ่ายแรก (ผู้ซื้อ): __________

注册地址：__________
法定代表人：__________
联系方式：__________

乙方（卖方）：__________
(Yǐ fāng (Mài fāng): __________)
ฝ่ายที่สอง (ผู้ขาย): __________
```

#### 3. 合同正文 (Hétong Zhèngwén) - เนื้อหาสัญญา

**มาตราสำคัญที่ต้องมีในสัญญาจีน:**

**第一条 标的 (Dì Yī Tiáo Biāodì) - มาตราที่ 1 วัตถุแห่งสัญญา**
```
本合同标的为：__________（以下简称"货物"）
(Běn hétong biāodì wéi: __________ (yǐxià jiǎnchēng "huòwù"))
วัตถุแห่งสัญญานี้คือ: __________ (เรียกย่อว่า "สินค้า")
```

**第二条 数量和质量 (Dì Èr Tiáo Shùliàng hé Zhìliàng) - มาตราที่ 2 ปริมาณและคุณภาพ**
```
1. 货物数量：__________
   (Huòwù shùliàng: __________)
   ปริมาณสินค้า: __________
   
2. 质量标准：符合__________标准
   (Zhìliàng biāozhǔn: fúhé __________ biāozhǔn)
   มาตรฐานคุณภาพ: ตรงตามมาตรฐาน __________
   
3. 验收方式：__________
   (Yànshōu fāngshì: __________)
   วิธีการตรวจรับ: __________
```

**第三条 价格和付款 (Dì Sān Tiáo Jiàgé hé Fùkuǎn) - มาตราที่ 3 ราคาและการชำระเงิน**
```
1. 合同总价：人民币/美元__________元
   (Hétong zǒng jià: Rénmínbì/Měiyuán __________ yuán)
   มูลค่าสัญญารวม: หยวน/ดอลลาร์ __________
   
2. 付款方式：
   首付：合同签署后____天内支付__________
   (Shǒufù: hétong qiānshǔ hòu ____ tiān nèi zhīfù __________)
   เงินดาวน์: ชำระภายใน ____ วันหลังลงนามสัญญา __________
   
   余款：__________
   (Yú kuǎn: __________)
   ยอดค้างชำระ: __________
```

**第四条 交货 (Dì Sì Tiáo Jiāohuò) - มาตราที่ 4 การส่งมอบ**
```
1. 交货地点：__________
   (Jiāohuò dìdiǎn: __________)
   สถานที่ส่งมอบ: __________
   
2. 交货时间：合同签署后____天内
   (Jiāohuò shíjiān: hétong qiānshǔ hòu ____ tiān nèi)
   เวลาส่งมอบ: ภายใน ____ วันหลังลงนามสัญญา
   
3. 风险转移：货物在交货时，风险由卖方转移至买方
   (Fēngxiǎn zhuǎnyí: huòwù zài jiāohuò shí, fēngxiǎn yóu mài fāng zhuǎnyí zhì mǎi fāng)
   การโอนความเสี่ยง: เมื่อส่งมอบสินค้า ความเสี่ยงโอนจากผู้ขายไปยังผู้ซื้อ
```

**第五条 违约责任 (Dì Wǔ Tiáo Wéiyuē Zérèn) - มาตราที่ 5 ความรับผิดในการละเมิดสัญญา**
```
1. 卖方违约：如卖方未能按时交货，每延迟一天，应向买方支付合同总价____%的违约金
   (Mài fāng wéiyuē: rú mài fāng wèi néng ànshí jiāohuò, měi yánchí yī tiān, yīng xiàng mǎi fāng zhīfù hétong zǒng jià ____% de wéiyuē jīn)
   การละเมิดโดยผู้ขาย: หากผู้ขายส่งมอบล่าช้า ให้ชำระค่าปรับแก่ผู้ซื้อ ____% ของมูลค่าสัญญาต่อวัน
   
2. 买方违约：如买方未能按时付款，每延迟一天，应向卖方支付未付款项____%的违约金
   (Mǎi fāng wéiyuē: rú mǎi fāng wèi néng ànshí fùkuǎn, měi yánchí yī tiān, yīng xiàng mài fāng zhīfù wèifù kuǎnxiàng ____% de wéiyuē jīn)
   การละเมิดโดยผู้ซื้อ: หากผู้ซื้อชำระเงินล่าช้า ให้ชำระค่าปรับแก่ผู้ขาย ____% ของยอดที่ค้างชำระต่อวัน
```

**第六条 不可抗力 (Dì Liù Tiáo Bùkě Kànglì) - มาตราที่ 6 เหตุสุดวิสัย**
```
如因不可抗力（包括但不限于自然灾害、战争、政府行为等）导致合同无法履行，
受影响方应在____天内书面通知另一方，并提供相关证明文件。
(Rú yīn bùkě kànglì (bāokuò dàn bù xiànyú zìrán zāihài, zhànzhēng, zhèngfǔ xíngwéi děng) dǎozhì hétong wúfǎ lǚxíng, shòu yǐngxiǎng fāng yīng zài ____ tiān nèi shūmiàn tōngzhī lìng yī fāng, bìng tígōng xiāngguān zhèngmíng wénjiàn.)
หากเนื่องจากเหตุสุดวิสัย (รวมถึงแต่ไม่จำกัดเพียงภัยพิบัติทางธรรมชาติ สงคราม การกระทำของรัฐบาล) ทำให้ไม่สามารถปฏิบัติตามสัญญา ฝ่ายที่ได้รับผลกระทบต้องแจ้งอีกฝ่ายเป็นลายลักษณ์อักษรภายใน ____ วัน พร้อมเอกสารหลักฐาน
```

**第七条 争议解决 (Dì Qī Tiáo Zhēngyì Jiějué) - มาตราที่ 7 การยุติข้อพิพาท**
```
本合同争议应首先通过双方协商解决。如协商不成，任何一方可向中国国际经济贸易仲裁委员会（CIETAC）提请仲裁。仲裁裁决为终局裁决，对双方均有约束力。
(Běn hétong zhēngyì yīng shǒuxiān tōngguò shuāng fāng xiéshāng jiějué. Rú xiéshāng bù chéng, rènhé yī fāng kě xiàng Zhōngguó Guójì Jīngjì Màoyì Zhòngcái Wěiyuánhuì (CIETAC) tíqǐng zhòngcái. Zhòngcái cáijué wéi zhōngjú cáijué, duì shuāng fāng jūn yǒu yuēshù lì.)
ข้อพิพาทตามสัญญานี้ให้ยุติโดยการเจรจาระหว่างคู่สัญญาก่อน หากเจรจาไม่สำเร็จ ฝ่ายใดฝ่ายหนึ่งอาจยื่นอนุญาโตตุลาการต่อ CIETAC คำชี้ขาดเป็นที่สุดและมีผลผูกพันทั้งสองฝ่าย
```

**第八条 适用法律 (Dì Bā Tiáo Shìyòng Fǎlǜ) - มาตราที่ 8 กฎหมายที่บังคับใช้**
```
本合同适用中华人民共和国法律。
(Běn hétong shìyòng Zhōnghuá Rénmín Gònghéguó fǎlǜ.)
```

## 💬 บทสนทนาระดับมืออาชีพ: การเจรจาสัญญา

### บทสนทนาที่ 1: การตรวจสอบเงื่อนไขสัญญา (Step 814)

**律师甲 (Lǜshī Jiǎ - ทนายความฝ่ายจีน):**
我们已经审查了贵方提供的合同草案，有几个条款需要进一步讨论。
(Wǒmen yǐjīng shěnchá le guì fāng tígōng de hétong cǎo'àn, yǒu jǐ gè tiáokuǎn xūyào jìnyībù tǎolùn.)
เราได้ตรวจสอบร่างสัญญาที่ฝ่ายท่านให้มาแล้ว มีบางข้อกำหนดที่ต้องหารือเพิ่มเติม

**律师乙 (Lǜshī Yǐ - ทนายความฝ่ายไทย):**
请直接提出您的意见，我们已准备好讨论每一个条款。
(Qǐng zhíjiē tíchū nín de yìjiàn, wǒmen yǐ zhǔnbèi hǎo tǎolùn měi yīgè tiáokuǎn.)
กรุณาแสดงความเห็นโดยตรง เราพร้อมหารือแต่ละข้อกำหนด

**律师甲:**
首先是违约金条款。草案规定的0.5%日违约金过高，我们建议降至0.1%。
(Shǒuxiān shì wéiyuē jīn tiáokuǎn. Cǎo'àn guīdìng de 0.5% rì wéiyuē jīn guò gāo, wǒmen jiànyì jiàng zhì 0.1%.)
อันดับแรกคือข้อกำหนดค่าปรับ ร่างสัญญากำหนดค่าปรับ 0.5% ต่อวันสูงเกินไป เราเสนอให้ลดเป็น 0.1%

**律师乙:**
0.1%可能不足以对违约行为产生足够的约束力。我们可以接受0.3%，但同时设定违约金的上限为合同总价的10%。
(0.1% kěnéng bùzú yǐ duì wéiyuē xíngwéi chǎnshēng zúgòu de yuēshù lì. Wǒmen kěyǐ jiēshòu 0.3%, dàn tóngshí shèdìng wéiyuē jīn de shànghéxiàn wéi hétong zǒng jià de 10%.)
0.1% อาจไม่เพียงพอที่จะสร้างแรงจูงใจในการปฏิบัติตาม เรายอมรับ 0.3% ได้ แต่ให้กำหนดเพดานค่าปรับที่ 10% ของมูลค่าสัญญารวม

### บทสนทนาที่ 2: การเจรจาข้อกำหนดเหตุสุดวิสัย (Step 815)

**法律顾问 (Fǎlǜ Gùwèn - ที่ปรึกษากฎหมาย):**
在不可抗力条款上，我们建议加入"政府政策变化"作为不可抗力事件之一。
(Zài bùkě kànglì tiáokuǎn shàng, wǒmen jiànyì jiārù "zhèngfǔ zhèngcè biànhuà" zuòwéi bùkě kànglì shìjiàn zhī yī.)
ในข้อกำหนดเหตุสุดวิสัย เราเสนอให้เพิ่ม "การเปลี่ยนแปลงนโยบายรัฐบาล" เป็นหนึ่งในเหตุสุดวิสัย

**对方律师 (Duì fāng Lǜshī - ทนายความฝ่ายตรงข้าม):**
这个定义太宽泛，可能被滥用。我们接受将政府直接行政命令导致合同无法履行的情况列为不可抗力，但政策变化本身不应构成不可抗力。
(Zhège dìngyì tài kuānfàn, kěnéng bèi lànyòng. Wǒmen jiēshòu jiāng zhèngfǔ zhíjiē xíngzhèng mìnglìng dǎozhì hétong wúfǎ lǚxíng de qíngkuàng liè wéi bùkě kànglì, dàn zhèngcè biànhuà běnshēn bù yīng gòuchéng bùkě kànglì.)
คำนิยามนี้กว้างเกินไป อาจถูกใช้ในทางที่ผิด เรายอมรับให้การที่คำสั่งบริหารโดยตรงของรัฐบาลทำให้ปฏิบัติตามสัญญาไม่ได้เป็นเหตุสุดวิสัย แต่การเปลี่ยนแปลงนโยบายเองไม่ควรเป็นเหตุสุดวิสัย

### บทสนทนาที่ 3: การเจรจาข้อกำหนดการยุติข้อพิพาท (Step 816)

**中方代理 (Zhōng Fāng Dàilǐ - ตัวแทนฝ่ายจีน):**

**泰方代理 (Tài Fāng Dàilǐ - ตัวแทนฝ่ายไทย):**
我们理解您的立场，但对于泰方而言，在中国仲裁在执行和公平性上存在顾虑。我们提议以香港国际仲裁中心（HKIAC）作为仲裁机构，以此来平衡双方的利益。
(Wǒmen lǐjiě nín de lìchǎng, dàn duìyú Tài fāng éryan, zài Zhōngguó zhòngcái zài zhíxíng hé gōngpíng xìng shàng cúnzài gùlǜ. Wǒmen tíyì yǐ Xiānggǎng Guójì Zhòngcái Zhōngxīn (HKIAC) zuòwéi zhòngcái jīgòu, yǐ cǐ lái pínghéng shuāng fāng de lìyì.)
เราเข้าใจจุดยืนของท่าน แต่สำหรับฝ่ายไทย มีข้อกังวลเรื่องการบังคับคดีและความยุติธรรมของการอนุญาโตตุลาการในจีน เราเสนอให้ใช้ HKIAC ซึ่งจะสร้างสมดุลผลประโยชน์ทั้งสองฝ่าย

**中方代理:**
香港对我们也是可以接受的，因为香港仲裁裁决在内地可以直接执行。我们同意HKIAC，但仲裁语言应包括中文。
(Xiānggǎng duì wǒmen yě shì kěyǐ jiēshòu de, yīnwèi Xiānggǎng zhòngcái cáijué zài nèidì kěyǐ zhíjiē zhíxíng. Wǒmen tóngyì HKIAC, dàn zhòngcái yǔyán yīng bāokuò Zhōngwén.)
ฮ่องกงก็ยอมรับได้สำหรับเรา เพราะคำชี้ขาดอนุญาโตตุลาการฮ่องกงสามารถบังคับใช้ในแผ่นดินใหญ่ได้โดยตรง เราเห็นด้วยกับ HKIAC แต่ภาษาอนุญาโตตุลาการต้องรวมภาษาจีน

### บทสนทนาที่ 4: การตรวจสอบและอนุมัติสัญญา (Step 817)

**CFO ไทย:**
在正式签约之前，我们的法律团队需要最后确认以下几点：第一，合同中文版与英文版如有歧义，以哪个版本为准？
(Zài zhèngshì qiān yuē zhīqián, wǒmen de fǎlǜ tuánduì xūyào zuìhòu quèrèn yǐxià jǐ diǎn: dì yī, hétong Zhōngwén bǎn yǔ Yīngwén bǎn rú yǒu qíyì, yǐ nǎ gè bǎnběn wéizhǔn?)
ก่อนลงนามอย่างเป็นทางการ ทีมกฎหมายของเราต้องยืนยันหลายประเด็น ข้อแรก ถ้ามีความขัดแย้งระหว่างฉบับภาษาจีนและอังกฤษ ให้ยึดฉบับใด?

**法务总监จีน:**
我建议两个版本具有同等法律效力，但在解释时优先参考中文版，因为合同适用中国法律。
(Wǒ jiànyì liǎng gè bǎnběn jùyǒu tóngtíng fǎlǜ xiàolì, dàn zài jiěshì shí yōuxiān cānkǎo Zhōngwén bǎn, yīnwèi hétong shìyòng Zhōngguó fǎlǜ.)
ผมเสนอให้ทั้งสองฉบับมีผลทางกฎหมายเท่ากัน แต่ในการตีความให้ยึดฉบับภาษาจีนเป็นหลัก เนื่องจากสัญญาใช้กฎหมายจีน

**CFO ไทย:**
这对我们来说难以接受。我们提议以英文版为准，因为我们的律师团队主要使用英文。
(Zhè duì wǒmen lái shuō nán yǐ jiēshòu. Wǒmen tíyì yǐ Yīngwén bǎn wéizhǔn, yīnwèi wǒmen de lǜshī tuánduì zhǔyào shǐyòng Yīngwén.)

**法务总监จีน:**
折中方案：在法律上两版同等效力，但争议条款由双方语言专家共同解释。
(Zhézhōng fāng'àn: zài fǎlǜ shàng liǎng bǎn tóngtíng xiàolì, dàn zhēngyì tiáokuǎn yóu shuāng fāng yǔyán zhuānjiā gòngtóng jiěshì.)
ทางออกกลางๆ: ทางกฎหมายทั้งสองฉบับมีผลเท่ากัน แต่ข้อกำหนดที่ขัดแย้งให้ผู้เชี่ยวชาญภาษาของทั้งสองฝ่ายตีความร่วมกัน

ขอบคุณทุกท่านที่เป็นสักขีพยานในช่วงเวลาสำคัญนี้ ความร่วมมือฉันมิตรระหว่างไทยและจีนจะได้รับการเสริมแน่นยิ่งขึ้นในการลงนามวันนี้ ขอให้ความร่วมมือราบรื่น!

### บทสนทนาที่ 6: การแก้ไขสัญญาระหว่างปฏิบัติงาน (Step 819)

**项目经理ไทย:**
由于原材料价格大幅上涨，我们需要商讨修订合同价格条款的可能性。
(Yóuyú yuáncáiliào jiàgé dàfú shàngzhǎng, wǒmen xūyào shāngqiāo xiūdìng hétong jiàgé tiáokuǎn de kěnéng xìng.)
เนื่องจากราคาวัตถุดิบเพิ่มสูงขึ้นมาก เราต้องหารือถึงความเป็นไปได้ในการแก้ไขข้อกำหนดราคาในสัญญา

**项目经理จีน:**
合同中有价格调整条款，但需要提供充分的市场证据。请提供过去三个月原材料价格变化的书面证明。
(Hétong zhōng yǒu jiàgé tiáozhěng tiáokuǎn, dàn xūyào tígōng chōngfèn de shìchǎng zhèngju. Qǐng tígōng guòqù sān gè yuè yuáncáiliào jiàgé biànhuà de shūmiàn zhèngmíng.)
สัญญามีข้อกำหนดการปรับราคาอยู่แล้ว แต่ต้องมีหลักฐานตลาดที่เพียงพอ กรุณาให้หลักฐานเป็นลายลักษณ์อักษรเกี่ยวกับการเปลี่ยนแปลงราคาวัตถุดิบสามเดือนที่ผ่านมา

**项目经理ไทย:**
我们已准备好相关资料，包括行业协会的价格指数报告和三家主要供应商的报价单。
(Wǒmen yǐ zhǔnbèi hǎo xiāngguān zīliào, bāokuò hángyè xiéhuì de jiàgé zhǐshù bàogào hé sān jiā zhǔyào gōngyìng shāng de bàojià dān.)
เราเตรียมเอกสารที่เกี่ยวข้องพร้อมแล้ว รวมถึงรายงานดัชนีราคาของสมาคมอุตสาหกรรมและใบเสนอราคาจากซัพพลายเออร์หลักสามราย

## 🔊 ประโยคฝึกทักษะด้านสัญญา (Step 820)

### ชุดที่ 1: การตรวจสอบเงื่อนไข

1. 请仔细审阅合同条款。(Qǐng zīxì shěnyuè hétong tiáokuǎn.) - กรุณาตรวจสอบข้อกำหนดสัญญาอย่างละเอียด
2. 这个条款需要进一步明确。(Zhège tiáokuǎn xūyào jìnyībù míngquè.) - ข้อกำหนดนี้ต้องชัดเจนขึ้น
3. 我们对第五条有异议。(Wǒmen duì dì wǔ tiáo yǒu yìyì.) - เรามีข้อโต้แย้งเกี่ยวกับมาตราที่ห้า
4. 请解释一下这个条款的含义。(Qǐng jiěshì yīxià zhège tiáokuǎn de hányì.) - กรุณาอธิบายความหมายของข้อกำหนดนี้
5. 合同中有没有关于知识产权的条款？(Hétong zhōng yǒu méiyǒu guānyú zhīshì chǎnquán de tiáokuǎn?) - สัญญามีข้อกำหนดเรื่องทรัพย์สินทางปัญญาหรือไม่?

### ชุดที่ 2: การเจรจาแก้ไขสัญญา

1. 我们需要对违约条款进行修改。(Wǒmen xūyào duì wéiyuē tiáokuǎn jìnxíng xiūgǎi.) - เราต้องแก้ไขข้อกำหนดการละเมิดสัญญา
2. 能否在合同中加入价格调整机制？(Néng fǒu zài hétong zhōng jiārù jiàgé tiáozhěng jīzhì?) - สามารถเพิ่มกลไกการปรับราคาในสัญญาได้ไหม?
3. 我们建议将保证期延长至三年。(Wǒmen jiànyì jiāng bǎozhèng qī yáncháng zhì sān nián.) - เราเสนอให้ขยายระยะประกันเป็น 3 ปี
4. 请在合同中明确定义"重大违约"。(Qǐng zài hétong zhōng míngquè dìngyì "zhòngdà wéiyuē".) - กรุณากำหนดนิยาม "การละเมิดที่เป็นสาระสำคัญ" ให้ชัดเจนในสัญญา
5. 我们希望加入终止权条款。(Wǒmen xīwàng jiārù zhōngzhǐ quán tiáokuǎn.) - เราต้องการเพิ่มข้อกำหนดสิทธิ์การยกเลิก

### ชุดที่ 3: การลงนามและการส่งมอบ

1. 双方均已确认合同条款无误。(Shuāng fāng jūn yǐ quèrèn hétong tiáokuǎn wúwù.) - ทั้งสองฝ่ายได้ยืนยันว่าข้อกำหนดสัญญาถูกต้องแล้ว
2. 请在指定位置签字盖章。(Qǐng zài zhǐdìng wèizhì qiānzì gài zhāng.) - กรุณาลงนามและประทับตราในที่กำหนด
3. 合同一式两份，双方各执一份。(Hétong yī shì liǎng fèn, shuāng fāng gè zhí yī fèn.) - สัญญาทำสองชุด แต่ละฝ่ายเก็บหนึ่งชุด
4. 请提供公司授权书。(Qǐng tígōng gōngsī shòuquán shū.) - กรุณาให้หนังสือมอบอำนาจบริษัท
5. 合同自双方签字之日起生效。(Hétong zì shuāng fāng qiānzì zhī rì qǐ shēngxiào.) - สัญญามีผลบังคับใช้ตั้งแต่วันที่ทั้งสองฝ่ายลงนาม

## 🏮 ระบบกฎหมายสัญญาและการยุติข้อพิพาทของจีน

### ระบบกฎหมายสัญญาจีน (中国合同法律体系)

#### กฎหมายหลักที่เกี่ยวข้อง:
1. **民法典 (Mínfǎ Diǎn) - ประมวลกฎหมายแพ่ง (2021)**
   - แทนที่กฎหมายสัญญาเดิม
   - ครอบคลุมสัญญาทุกประเภท
   - มีผลตั้งแต่ 1 มกราคม 2021

2. **涉外合同法 (Shèwài Hétong Fǎ) - กฎหมายสัญญาต่างชาติ**
   - สัญญาระหว่างบริษัทจีนและต่างชาติ
   - ข้อกำหนดพิเศษสำหรับ FDI

3. **仲裁法 (Zhòngcái Fǎ) - กฎหมายอนุญาโตตุลาการ**
   - กำกับดูแล CIETAC และสถาบันอนุญาโตตุลาการอื่นๆ

#### CIETAC (中国国际经济贸易仲裁委员会):
- ก่อตั้งปี 1956
- หนึ่งในสถาบันอนุญาโตตุลาการที่ใหญ่ที่สุดในโลก
- ยอมรับสากล
- มีสาขาในปักกิ่ง เซี่ยงไฮ้ และทั่วโลก

**คำศัพท์ CIETAC:**
- 申请人 (Shēnqǐng rén) - ผู้ยื่น/ผู้ร้อง
- 被申请人 (Bèi shēnqǐng rén) - ผู้ถูกร้อง
- 仲裁申请书 (Zhòngcái shēnqǐng shū) - หนังสือยื่นอนุญาโตตุลาการ
- 仲裁庭 (Zhòngcái tíng) - คณะอนุญาโตตุลาการ
- 裁决书 (Cáijué shū) - คำชี้ขาด

## ✏️ แบบฝึกหัด

### แบบฝึกหัดที่ 1: การอ่านสัญญา

อ่านข้อความสัญญาต่อไปนี้และตอบคำถาม:

```
第十二条 付款方式
1. 甲方应在签约后30日内支付合同总价的30%作为预付款。
2. 乙方完成货物交付并经甲方验收合格后，甲方应在15个工作日内支付合同总价的50%。
3. 质保期满且无质量问题后，甲方应支付剩余20%的尾款。
4. 如甲方逾期付款，每逾期一日，应按未付款项0.05%计算违约金。
```

**คำถาม:**
1. ชำระเงินทั้งหมดกี่งวด?
2. เงินดาวน์ชำระเมื่อไหร่และเท่าไหร่?
3. ค่าปรับการชำระล่าช้าคิดอย่างไร?

### แบบฝึกหัดที่ 2: การเขียนสัญญา

ร่างข้อกำหนดต่อไปนี้เป็นภาษาจีน:
1. ข้อกำหนดการรับประกันสินค้า 2 ปี
2. ข้อกำหนดห้ามการแข่งขัน 3 ปี
3. ข้อกำหนดการชำระเงินล่วงหน้า 20%

### แบบฝึกหัดที่ 3: การแปล

แปลข้อกำหนดต่อไปนี้จากภาษาไทยเป็นภาษาจีน:
"ในกรณีที่ฝ่ายใดฝ่ายหนึ่งไม่สามารถปฏิบัติตามข้อกำหนดของสัญญาได้เนื่องจากเหตุสุดวิสัย ฝ่ายดังกล่าวต้องแจ้งอีกฝ่ายภายใน 5 วันทำการ พร้อมเอกสารหลักฐานที่เกี่ยวข้อง"
