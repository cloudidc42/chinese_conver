## 步骤 601 | โครงสร้าง 如果...就 (ถ้า...ก็)

### 📝 โครงสร้าง:
```
如果 + [เงื่อนไข] + 就 + [ผลลัพธ์]
Rúguǒ + [condition] + jiù + [result]
```

### 💡 กฎสำคัญ:
- 如果 (rúguǒ) อยู่ต้นประโยคเงื่อนไข
- 就 (jiù) อยู่ต้นประโยคผลลัพธ์
- ประธานสามารถอยู่ก่อนหรือหลัง 如果 ได้
- ในภาษาพูด บางครั้งละ 如果 หรือ 就 ได้

### 📖 ตัวอย่างประโยค:

**ระดับพื้นฐาน:**
1. 如果明天下雨，我就不去了。
   Rúguǒ míngtiān xià yǔ, wǒ jiù bù qù le.
   ถ้าพรุ่งนี้ฝนตก ฉันก็จะไม่ไปแล้ว

2. 如果你有时间，就来我家玩吧。
   Rúguǒ nǐ yǒu shíjiān, jiù lái wǒ jiā wán ba.
   ถ้าคุณมีเวลา ก็มาเที่ยวบ้านฉันนะ

3. 如果价格合适，我就买。
   Rúguǒ jiàgé héshì, wǒ jiù mǎi.
   ถ้าราคาเหมาะสม ฉันก็จะซื้อ

**ระดับกลาง:**
4. 如果你能来参加会议，那就太好了。
   Rúguǒ nǐ néng lái cānjiā huìyì, nà jiù tài hǎo le.
   ถ้าคุณสามารถมาร่วมประชุมได้ นั่นก็ดีมากเลย

5. 如果这个项目成功了，公司就会扩大规模。
   Rúguǒ zhège xiàngmù chénggōng le, gōngsī jiù huì kuòdà guīmó.
   ถ้าโปรเจกต์นี้สำเร็จ บริษัทก็จะขยายขนาด

6. 如果你不努力学习，就很难通过考试。
   Rúguǒ nǐ bù nǔlì xuéxí, jiù hěn nán tōngguò kǎoshì.
   ถ้าคุณไม่เรียนหนัก ก็ยากที่จะผ่านการสอบ

**ระดับสูง:**
7. 如果当时做了不同的选择，现在的生活可能会完全不同。
   Rúguǒ dāngshí zuò le bùtóng de xuǎnzé, xiànzài de shēnghuó kěnéng huì wánquán bùtóng.
   ถ้าตอนนั้นทำการเลือกที่แตกต่างออกไป ชีวิตตอนนี้อาจจะแตกต่างออกไปอย่างสิ้นเชิง

8. 如果这项政策能够有效实施，就将对经济产生深远影响。
   Rúguǒ zhè xiàng zhèngcè nénggòu yǒuxiào shíshī, jiù jiāng duì jīngjì chǎnshēng shēnyuǎn yǐngxiǎng.
   ถ้านโยบายนี้สามารถนำไปใช้ได้อย่างมีประสิทธิภาพ ก็จะส่งผลกระทบอย่างลึกซึ้งต่อเศรษฐกิจ

## 步骤 602 | โครงสร้าง 因为...所以 (เพราะ...ดังนั้น)

### 📝 โครงสร้าง:
```
因为 + [เหตุผล] + 所以 + [ผลลัพธ์]
Yīnwèi + [reason] + suǒyǐ + [result]
```

### 💡 กฎสำคัญ:
- สามารถใช้ 因为 อย่างเดียวโดยไม่ต้องมี 所以
- สามารถใช้ 所以 อย่างเดียวโดยไม่ต้องมี 因为
- ใช้ทั้งคู่เพื่อเน้นความสัมพันธ์เหตุผล

### 📖 ตัวอย่างประโยค:

1. 因为他很努力，所以成绩很好。
   Yīnwèi tā hěn nǔlì, suǒyǐ chéngjì hěn hǎo.
   เพราะเขาขยันมาก ดังนั้นผลการเรียนจึงดี

2. 因为下雨了，所以我们取消了野餐。
   Yīnwèi xià yǔ le, suǒyǐ wǒmen qǔxiāo le yěcān.
   เพราะฝนตก ดังนั้นเราจึงยกเลิกการปิกนิก

3. 因为交通堵塞，所以他迟到了。
   Yīnwèi jiāotōng dǔsè, suǒyǐ tā chídào le.
   เพราะรถติด ดังนั้นเขาจึงมาสาย

4. 因为缺乏经验，所以他在工作中犯了很多错误。
   Yīnwèi quēfá jīngyàn, suǒyǐ tā zài gōngzuò zhōng fàn le hěn duō cuòwù.
   เพราะขาดประสบการณ์ ดังนั้นเขาจึงทำผิดพลาดมากในการทำงาน

5. 正因为困难，才更值得努力。
   Zhèng yīnwèi kùnnán, cái gèng zhídé nǔlì.
   ก็เพราะว่ายาก จึงยิ่งคุ้มค่าที่จะพยายาม

6. 因为公司业绩不佳，所以决定重组管理团队。
   Yīnwèi gōngsī yèjì bù jiā, suǒyǐ juédìng chóngzǔ guǎnlǐ tuánduì.
   เพราะผลประกอบการบริษัทไม่ดี ดังนั้นจึงตัดสินใจปรับโครงสร้างทีมบริหาร

## 步骤 603 | โครงสร้าง 虽然...但是 (แม้ว่า...แต่)

### 📝 โครงสร้าง:
```
虽然 + [สถานการณ์] + 但是/可是/却 + [ผลลัพธ์ที่ขัดแย้ง]
Suīrán + [situation] + dànshì/kěshì/què + [contrasting result]
```

### 💡 กฎสำคัญ:
- 虽然 แสดงความยอมรับสถานการณ์หนึ่ง
- 但是/可是 แสดงความขัดแย้งหรือผลลัพธ์ที่ไม่คาดคิด
- 却 (què) ใช้ในภาษาเขียนหรือทางการ
- สามารถละ 虽然 ได้และใช้แค่ 但是 ก็ได้

### 📖 ตัวอย่างประโยค:

1. 虽然很累，但是我还是要坚持。
   Suīrán hěn lèi, dànshì wǒ háishì yào jiānchí.
   แม้ว่าจะเหนื่อยมาก แต่ฉันก็ยังจะต้องอดทน

2. 虽然他年纪很小，但是非常懂事。
   Suīrán tā niánjì hěn xiǎo, dànshì fēicháng dǒngshì.
   แม้ว่าเขาจะอายุน้อย แต่ก็เข้าใจเรื่องราวดีมาก

3. 虽然这道题很难，但是他还是做出来了。
   Suīrán zhè dào tí hěn nán, dànshì tā háishì zuò chūlái le.
   แม้ว่าโจทย์ข้อนี้จะยากมาก แต่เขาก็ยังทำได้

4. 虽然价格不便宜，但是质量确实很好。
   Suīrán jiàgé bù piányí, dànshì zhìliàng quèshí hěn hǎo.
   แม้ว่าราคาจะไม่ถูก แต่คุณภาพดีจริงๆ

5. 虽然困难重重，他却从未放弃。
   Suīrán kùnnán chóngchóng, tā què cóng wèi fàngqì.
   แม้ว่าจะมีความยากลำบากมากมาย แต่เขาก็ไม่เคยยอมแพ้

6. 虽然我们团队规模不大，但是我们的执行力非常强。
   Suīrán wǒmen tuánduì guīmó bù dà, dànshì wǒmen de zhíxínglì fēicháng qiáng.
   แม้ว่าทีมของเราจะไม่ใหญ่ แต่ความสามารถในการปฏิบัติงานของเราแข็งแกร่งมาก

7. 虽然这个方案存在一些问题，但总体上来说还是可行的。
   Suīrán zhège fāng'àn cúnzài yīxiē wèntí, dàn zǒngtǐ shàng lái shuō háishì kěxíng de.
   แม้ว่าแผนนี้จะมีปัญหาบางอย่าง แต่โดยรวมแล้วก็ยังเป็นไปได้

## 步骤 604 | โครงสร้าง 不仅...而且 (ไม่เพียงแต่...แต่ยัง)

### 📝 โครงสร้าง:
```
不仅/不只/不光 + [สิ่งแรก] + 而且/还/也 + [สิ่งที่สอง]
Bùjǐn/bùzhǐ/bùguāng + [first] + érqiě/hái/yě + [second]
```

### 📖 ตัวอย่างประโยค:

1. 她不仅会说中文，而且还会说日语。
   Tā bùjǐn huì shuō Zhōngwén, érqiě hái huì shuō Rìyǔ.
   เธอไม่เพียงแต่พูดภาษาจีนได้ แต่ยังพูดภาษาญี่ปุ่นได้ด้วย

2. 这家餐厅不仅饭菜好吃，环境也很好。
   Zhè jiā cāntīng bùjǐn fàncài hǎochī, huánjìng yě hěn hǎo.
   ร้านอาหารนี้ไม่เพียงแต่อาหารอร่อย แต่บรรยากาศก็ดีด้วย

3. 这项技术不仅提高了效率，而且降低了成本。
   Zhè xiàng jìshù bùjǐn tígāo le xiàolǜ, érqiě jiàngdī le chéngběn.
   เทคโนโลยีนี้ไม่เพียงแต่เพิ่มประสิทธิภาพ แต่ยังลดต้นทุนด้วย

4. 不仅学生受益，老师们也从中学到了很多。
   Bùjǐn xuéshēng shòuyì, lǎoshīmen yě cóng zhōng xuédào le hěn duō.
   ไม่เพียงแต่นักเรียนได้ประโยชน์ แต่คุณครูก็ยังเรียนรู้ได้มากมายจากนั้นด้วย

5. 这次合作不仅带来了经济效益，而且还加深了两国之间的友谊。
   Zhè cì hézuò bùjǐn dài lái le jīngjì xiàoyì, érqiě hái jiāshēn le liǎng guó zhī jiān de yǒuyì.
   ความร่วมมือครั้งนี้ไม่เพียงแต่นำมาซึ่งผลประโยชน์ทางเศรษฐกิจ แต่ยังช่วยกระชับมิตรภาพระหว่างสองประเทศด้วย

## 步骤 605 | โครงสร้าง 既...又 (ทั้ง...และ)

### 📝 โครงสร้าง:
```
既 + [คุณสมบัติแรก] + 又/也 + [คุณสมบัติที่สอง]
Jì + [quality 1] + yòu/yě + [quality 2]
```

### 💡 หมายเหตุ:
- 既...又 ใช้กับคุณสมบัติเชิงบวกหรือเชิงลบก็ได้
- แต่ทั้งสองต้องมีลักษณะเดียวกัน (บวกทั้งคู่ หรือลบทั้งคู่)
- ต่างจาก 又...又 ที่ใช้กับเหตุการณ์ที่เกิดพร้อมกัน

### 📖 ตัวอย่างประโยค:

1. 她既漂亮又聪明。
   Tā jì piàoliang yòu cōngmíng.
   เธอทั้งสวยและฉลาด

2. 这道菜既好看又好吃。
   Zhè dào cài jì hǎokàn yòu hǎochī.
   อาหารจานนี้ทั้งสวยและอร่อย

3. 这个工作既有挑战性又有成就感。
   Zhège gōngzuò jì yǒu tiǎozhànxìng yòu yǒu chéngjiùgǎn.
   งานนี้ทั้งท้าทายและให้ความรู้สึกของความสำเร็จ

4. 他既不吃肉，也不喝酒。
   Tā jì bù chī ròu, yě bù hē jiǔ.
   เขาทั้งไม่กินเนื้อและไม่ดื่มเหล้า

5. 这种材料既轻便又耐用，非常适合户外使用。
   Zhèzhǒng cáiliào jì qīngbiàn yòu nàiyòng, fēicháng shìhé hùwài shǐyòng.
   วัสดุชนิดนี้ทั้งเบาและทนทาน เหมาะมากสำหรับการใช้งานกลางแจ้ง

## 步骤 606 | โครงสร้าง 无论/不管...都 (ไม่ว่าจะ...ก็)

### 📝 โครงสร้าง:
```
无论/不管 + [คำถาม/เงื่อนไข] + 都/也 + [ผลลัพธ์]
Wúlùn/bùguǎn + [question/condition] + dōu/yě + [result]
```

### 💡 กฎสำคัญ:
- มักตามด้วยคำถาม: 什么 (shénme), 谁 (shuí), 哪里 (nǎlǐ), 怎么 (zěnme), 多少 (duōshǎo)
- หรือตามด้วยโครงสร้าง A 还是 B
- 都 (dōu) บ่งบอกว่าผลลัพธ์เกิดขึ้นในทุกกรณี

### 📖 ตัวอย่างประโยค:

1. 无论发生什么，我都支持你。
   Wúlùn fāshēng shénme, wǒ dōu zhīchí nǐ.
   ไม่ว่าจะเกิดอะไรขึ้น ฉันก็สนับสนุนคุณ

2. 不管天气怎么样，他都会去跑步。
   Bùguǎn tiānqì zěnmeyàng, tā dōu huì qù pǎobù.
   ไม่ว่าอากาศจะเป็นอย่างไร เขาก็จะไปวิ่ง

3. 无论多忙，她都会给家人打电话。
   Wúlùn duō máng, tā dōu huì gěi jiārén dǎ diànhuà.
   ไม่ว่าจะยุ่งแค่ไหน เธอก็จะโทรหาครอบครัว

4. 不管遇到什么困难，我们都不能放弃。
   Bùguǎn yùdào shénme kùnnán, wǒmen dōu bù néng fàngqì.
   ไม่ว่าจะพบกับความยากลำบากอะไร เราก็ต้องไม่ยอมแพ้

5. 无论你同意还是不同意，这个决定已经做出了。
   Wúlùn nǐ tóngyì háishì bù tóngyì, zhège juédìng yǐjīng zuò chū le.
   ไม่ว่าคุณจะเห็นด้วยหรือไม่เห็นด้วย การตัดสินใจนี้ก็ได้ทำไปแล้ว

6. 无论市场如何变化，我们都要坚守我们的核心价值。
   Wúlùn shìchǎng rúhé biànhuà, wǒmen dōu yào jiānshǒu wǒmen de héxīn jiàzhí.
   ไม่ว่าตลาดจะเปลี่ยนแปลงอย่างไร เราก็ต้องยึดมั่นในคุณค่าหลักของเรา

## 步骤 607 | โครงสร้าง 只有...才 (ก็ต่อเมื่อ)

### 📝 โครงสร้าง:
```
只有 + [เงื่อนไขจำเป็น] + 才 + [ผลลัพธ์]
Zhǐyǒu + [necessary condition] + cái + [result]
```

### 💡 ความแตกต่าง:
- **只有...才** = ก็ต่อเมื่อ (เงื่อนไขจำเป็นและเพียงพอ)
- **只要...就** = ตราบใดที่ (เงื่อนไขเพียงพอ ไม่จำเป็นต้องเป็นเงื่อนไขเดียว)

### 📖 ตัวอย่างประโยค:

1. 只有努力才能成功。
   Zhǐyǒu nǔlì cái néng chénggōng.
   ก็ต่อเมื่อพยายามอย่างหนักจึงจะประสบความสำเร็จ

## 🏮 วัฒนธรรมและการใช้ภาษา

### 📌 การใช้คำเชื่อมในสถานการณ์ต่างๆ

**ในธุรกิจ:**
- ใช้ 如果...就 บ่อยในการเจรจา
- 只有...才 เน้นเงื่อนไขสำคัญ
- 不仅...而且 ใช้เมื่อนำเสนอข้อดีหลายประการ

**ในการเขียนทางการ:**
- 虽然...但是/然而 เป็นทางการมาก
- 因此 (yīncǐ) แทน 所以 ในภาษาเขียน
- 尽管...但 (jǐnguǎn...dàn) ทางการกว่า 虽然...但是

**ในการสนทนา:**
- 不管...都 ใช้บ่อยกว่า 无论...都
- 要是...就 ใช้บ่อยกว่า 如果...就 ในภาษาพูด

## ✏️ แบบฝึกหัด (60+ ข้อ)

### แบบฝึกหัดที่ 1: เติมคำเชื่อมที่เหมาะสม (20 ข้อ)

3. _____ 交通不方便，_____ 他每天坚持骑车上班。
4. 这道菜_____ 好看_____ 好吃。
5. _____ 努力，_____ 能实现目标。
6. 他_____ 到家_____ 打开电视。

8. 她_____ 刻苦学习_____ 能通过了高考。
9. _____ 你去哪里，我_____ 支持你。
10. 他_____ 午夜_____ 完成了报告。
11. _____ 下雨，_____ 带伞出门。
12. _____ 这件事很难，_____ 我们一定要想办法解决。
13. _____ 你在哪里，_____ 要保持联系。

### แบบฝึกหัดที่ 2: แปลเป็นภาษาจีน (20 ข้อ)

1. ถ้าคุณไม่เข้าใจ ก็ถามได้เลย
2. เพราะเขาซื่อสัตย์ ทุกคนจึงไว้วางใจเขา
3. แม้ว่าจะล้มเหลว แต่เขาก็ไม่เสียใจ
4. เธอไม่เพียงแต่ฉลาด แต่ยังทำงานหนักด้วย
5. ไม่ว่าจะยากแค่ไหน เขาก็ไม่ยอมแพ้
6. ก็ต่อเมื่อเข้าใจปัญหา จึงจะแก้ไขได้
7. ทันทีที่ฝนตก เธอก็กลับเข้าบ้าน
8. ยิ่งเรียนรู้ ยิ่งรู้สึกว่าตัวเองรู้น้อย
9. เขาจนถึงเที่ยงคืนจึงนอนหลับ
10. เมืองนี้ทั้งใหญ่และสวยงาม
11. ถ้าธุรกิจขยายตัว เราจะต้องจ้างพนักงานเพิ่ม
12. เพราะตลาดมีการเปลี่ยนแปลง บริษัทจึงต้องปรับตัว
13. แม้ว่าราคาจะสูง แต่คุณภาพก็คุ้มค่า
14. ไม่เพียงแต่ลูกค้าพึงพอใจ แต่พนักงานก็ภูมิใจด้วย
15. ยิ่งทำงานร่วมกัน ยิ่งมีความสามัคคี
16. ทันทีที่ผู้จัดการเข้ามา การประชุมก็เริ่มต้น
17. ไม่ว่าตลาดจะผันผวน เราก็ต้องยึดมั่นในหลักการ
18. ก็ต่อเมื่อทุกคนเข้าใจกลยุทธ์ การดำเนินงานจึงจะราบรื่น
19. ทั้งในแง่คุณภาพและราคา สินค้าของเราดีกว่าคู่แข่ง
20. จนกระทั่งปัญหาได้รับการแก้ไข โครงการจึงจะดำเนินต่อไปได้

### แบบฝึกหัดที่ 3: สร้างประโยคจากสถานการณ์ (20 ข้อ)

ใช้โครงสร้างที่กำหนด สร้างประโยคจากสถานการณ์:

1. (如果...就) สถานการณ์: คุณต้องการโน้มน้าวให้เพื่อนร่วมงานยอมรับข้อเสนอ
2. (虽然...但是) สถานการณ์: อธิบายว่าทำไมจึงยังทำงานแม้จะเหนื่อย
3. (不仅...而且) สถานการณ์: แนะนำร้านอาหารที่ดี
4. (无论...都) สถานการณ์: บอกเพื่อนว่าจะสนับสนุนเขาเสมอ
5. (只有...才) สถานการณ์: อธิบายเงื่อนไขของความสำเร็จ

## 📖 สรุป Part 061

### โครงสร้างที่เรียนในบทนี้:

| โครงสร้าง | ความหมาย | ระดับการใช้ |
|----------|----------|------------|
| 如果...就 | ถ้า...ก็ | พื้นฐาน-สูง |
| 因为...所以 | เพราะ...ดังนั้น | พื้นฐาน-สูง |
| 虽然...但是 | แม้ว่า...แต่ | กลาง-สูง |
| 不仅...而且 | ไม่เพียงแต่...แต่ยัง | กลาง-สูง |
| 既...又 | ทั้ง...และ | กลาง |
| 无论...都 | ไม่ว่าจะ...ก็ | สูง |
| 只有...才 | ก็ต่อเมื่อ | สูง |
| 一...就 | ทันทีที่ | สูง |
| 直到...才 | จนกระทั่ง | สูง |
| 越...越 | ยิ่ง...ยิ่ง | สูง |

### 💡 เคล็ดลับการจำ:
1. ฝึกใช้โครงสร้างเหล่านี้ในการสนทนาจริงทุกวัน
2. สังเกตว่าแต่ละโครงสร้างใช้ในสถานการณ์ใด
3. ในการเขียนทางการ ใช้รูปแบบที่เป็นทางการกว่า
4. ในการสนทนา สามารถย่อหรือปรับได้ตามธรรมชาติ
