# ภาษาจีนกลาง Part 044: การเปรียบเทียบ (Comparison Patterns)
## 步骤 431-440 | ระดับ: กลาง (Intermediate)

---

## 🎯 วัตถุประสงค์การเรียนรู้

หลังจากเรียนจบ Part นี้ ผู้เรียนจะสามารถ:
1. ใช้ 比 (bǐ) เปรียบเทียบสองสิ่งได้อย่างถูกต้อง
2. ใช้ 没有 (méiyǒu) บอกว่าสิ่งหนึ่งด้อยกว่าอีกสิ่ง
3. ใช้ 一样 (yīyàng) บอกความเหมือน
4. ใช้ 最 (zuì) และ 更 (gèng) ในการเปรียบเทียบ
5. สร้างประโยคเปรียบเทียบแบบซับซ้อน

## 📚 คำศัพท์สำคัญ

### ตาราง 1: คำวิเศษณ์ในการเปรียบเทียบ

| คำ | Pinyin | ความหมาย | ตัวอย่าง |
|----|--------|----------|---------|
| 比 | bǐ | มากกว่า / เทียบกับ | A比B高 (A สูงกว่า B) |
| 没有 | méiyǒu | ไม่เท่า / น้อยกว่า | A没有B高 (A ไม่สูงเท่า B) |
| 一样 | yīyàng | เหมือนกัน | A跟B一样高 (A สูงเท่ากับ B) |
| 不如 | bùrú | สู้ไม่ได้ | A不如B (A ไม่ดีเท่า B) |
| 最 | zuì | ที่สุด | 最高 (สูงที่สุด) |
| 更 | gèng | ยิ่ง...มากขึ้น | 更高 (สูงกว่าเดิมอีก) |
| 还 | hái | ยัง...กว่า | 还高 (ยังสูงกว่า) |
| 差不多 | chàbuduō | พอๆ กัน | 差不多一样 (แทบจะเหมือนกัน) |
| 远不如 | yuǎn bùrú | ห่างชั้นกัน | A远不如B (A ยังห่างไกล B) |
| 比较 | bǐjiào | ค่อนข้าง / เมื่อเปรียบเทียบ | 比较高 (ค่อนข้างสูง) |

### ตาราง 2: คำคุณศัพท์ในการเปรียบเทียบ

| คำคุณศัพท์ | Pinyin | ความหมาย | ตรงข้าม |
|-----------|--------|----------|--------|
| 高 | gāo | สูง | 矮 (ǎi) เตี้ย |
| 大 | dà | ใหญ่ | 小 (xiǎo) เล็ก |

| 快 | kuài | เร็ว | 慢 (màn) ช้า |

| 好 | hǎo | ดี | 坏 (huài) แย่ |

## 📝 ไวยากรณ์: Comparison Patterns

### 步骤 431: A 比 B + Adj (A มากกว่า B)

**โครงสร้างพื้นฐาน:**
```
A + 比 + B + 形容词
A + bǐ + B + Adjective
```

**ตัวอย่างพื้นฐาน:**
1. 我**比**他高。Wǒ **bǐ** tā gāo. → ฉันสูงกว่าเขา
2. 这个**比**那个贵。Zhège **bǐ** nàge guì. → อันนี้แพงกว่าอันนั้น
3. 北京**比**上海冷。Běijīng **bǐ** Shànghǎi lěng. → ปักกิ่งหนาวกว่าเซี่ยงไฮ้
4. 今天**比**昨天热。Jīntiān **bǐ** zuótiān rè. → วันนี้ร้อนกว่าเมื่อวาน

**เพิ่มระดับความแตกต่าง (多/得多/一点儿):**
1. 他**比**我高**得多**。Tā **bǐ** wǒ gāo **de duō**. → เขาสูงกว่าฉันมาก
2. 这个**比**那个贵**一点儿**。Zhège **bǐ** nàge guì **yīdiǎnr**. → อันนี้แพงกว่าอันนั้นนิดหน่อย
3. 中文**比**英文难**多了**。Zhōngwén **bǐ** Yīngwén nán **duō le**. → ภาษาจีนยากกว่าภาษาอังกฤษมากเลย

**กฎสำคัญ:**
- ❌ 我比他更高。(ผิด - ห้ามใช้ 更 กับ 比 โดยตรง)
- ✅ 我比他高。/ 我比他高得多。(ถูก)

### 步骤 432: A 没有 B + Adj (A ไม่เท่า B / น้อยกว่า B)

**โครงสร้าง:**
```
A + 没有 + B + 形容词
```

**ตัวอย่าง:**
1. 我**没有**他高。Wǒ **méiyǒu** tā gāo. → ฉันไม่สูงเท่าเขา
2. 这个**没有**那个贵。Zhège **méiyǒu** nàge guì. → อันนี้ไม่แพงเท่าอันนั้น
3. 上海**没有**北京冷。Shànghǎi **méiyǒu** Běijīng lěng. → เซี่ยงไฮ้ไม่หนาวเท่าปักกิ่ง
4. 今天**没有**昨天热。Jīntiān **méiyǒu** zuótiān rè. → วันนี้ไม่ร้อนเท่าเมื่อวาน

**เปรียบเทียบ 比 vs 没有:**

| ประโยค | ความหมาย |
|--------|---------|
| 他比我高。Tā bǐ wǒ gāo. | เขาสูงกว่าฉัน |
| 我没有他高。Wǒ méiyǒu tā gāo. | ฉันไม่สูงเท่าเขา (ความหมายเหมือนกัน แต่มุมมองต่างกัน) |

### 步骤 433: A 跟/和 B 一样 (A เหมือน B)

**โครงสร้าง:**
```
A + 跟/和 + B + 一样 (+形容词)
```

**ตัวอย่าง:**
1. 我**跟**他**一样**高。Wǒ **gēn** tā **yīyàng** gāo. → ฉันสูงเท่ากับเขา
2. 这件衣服**和**那件**一样**贵。Zhè jiàn yīfú **hé** nà jiàn **yīyàng** guì. → เสื้อตัวนี้แพงเท่ากับตัวนั้น
3. 我们的想法**跟**你**一样**。Wǒmen de xiǎngfǎ **gēn** nǐ **yīyàng**. → ความคิดของเราเหมือนกับคุณ
4. 今天的天气**和**昨天**一样**热。Jīntiān de tiānqì **hé** zuótiān **yīyàng** rè. → อากาศวันนี้ร้อนเท่ากับเมื่อวาน

**ปฏิเสธ: 不一样 (ไม่เหมือนกัน)**
1. 我们**不一样**。Wǒmen **bù yīyàng**. → เราไม่เหมือนกัน
2. 他跟我**不一样**高。Tā gēn wǒ **bù yīyàng** gāo. → เขาไม่ได้สูงเท่ากับฉัน

### 步骤 434: A 不如 B (A สู้ B ไม่ได้)

**โครงสร้าง:**
```
A + 不如 + B (+ 形容词)
```

**ตัวอย่าง:**
1. 我**不如**他聪明。Wǒ **bùrú** tā cōngmíng. → ฉันฉลาดไม่เท่าเขา / ฉันสู้เขาไม่ได้เรื่องความฉลาด
2. 这家餐厅**不如**那家好吃。Zhè jiā cāntīng **bùrú** nà jiā hǎo chī. → ร้านอาหารนี้ไม่อร่อยเท่าร้านนั้น
3. 我的汉语**不如**他好。Wǒ de Hànyǔ **bùrú** tā hǎo. → ภาษาจีนของฉันไม่ดีเท่าของเขา
4. 纸质书**不如**电子书方便。Zhǐzhì shū **bùrú** diànzǐ shū fāngbiàn. → หนังสือกระดาษสะดวกไม่เท่าหนังสืออิเล็กทรอนิกส์

> **หมายเหตุ:** 不如 มีนัยว่า "ด้อยกว่า" ไม่เหมาะกับสถานการณ์ที่เป็นกลาง

### 步骤 435: 最 (zuì) - ที่สุด

**โครงสร้าง:**
```
最 + 形容词/动词
```

**ตัวอย่าง:**
1. 他是班里**最**高的学生。Tā shì bān lǐ **zuì** gāo de xuéshēng. → เขาเป็นนักเรียนที่สูงที่สุดในชั้น
2. 这是**最**好吃的餐厅。Zhè shì **zuì** hǎo chī de cāntīng. → นี่เป็นร้านอาหารที่อร่อยที่สุด
3. 我**最**喜欢学汉语。Wǒ **zuì** xǐhuān xué Hànyǔ. → ฉันชอบเรียนภาษาจีนที่สุด
4. 这道菜是中国**最**有名的。Zhè dào cài shì Zhōngguó **zuì** yǒumíng de. → อาหารจานนี้เป็นที่โด่งดังที่สุดในจีน
5. 今年夏天是**最**热的一年。Jīnnián xiàtiān shì **zuì** rè de yī nián. → ฤดูร้อนปีนี้เป็นปีที่ร้อนที่สุด

### 步骤 436: 更 (gèng) - ยิ่ง...มากขึ้น

**โครงสร้าง:**
```
更 + 形容词
A 比 B 更 + 形容词 (เมื่อ 更 อยู่หลัง 比)
```

**ตัวอย่าง:**
1. 今天**更**冷了。Jīntiān **gèng** lěng le. → วันนี้หนาวมากขึ้น
2. 这个**更**好。Zhège **gèng** hǎo. → อันนี้ดีกว่า
3. 他比我**更**努力。Tā bǐ wǒ **gèng** nǔlì. → เขาพยายามมากกว่าฉน
4. 这个方法**更**有效。Zhège fāngfǎ **gèng** yǒuxiào. → วิธีนี้มีประสิทธิภาพกว่า

> **ข้อควรระวัง:** ใช้ 更 ใน A 比 B 更 Adj ได้ แต่ไม่ใช้ 更 ตรงๆ กับ 比 โดยไม่มีคำอื่น

### 步骤 437: การเปรียบเทียบแบบซับซ้อน

**1. A 比 B + Adj + Quantity (แตกต่างเท่าไหร่)**
1. 他比我高**三厘米**。Tā bǐ wǒ gāo **sān límǐ**. → เขาสูงกว่าฉันสามเซนติเมตร
2. 这个比那个贵**五块**。Zhège bǐ nàge guì **wǔ kuài**. → อันนี้แพงกว่าอันนั้นห้าหยวน
3. 今天比昨天热**两度**。Jīntiān bǐ zuótiān rè **liǎng dù**. → วันนี้ร้อนกว่าเมื่อวานสององศา

**2. 越...越... (ยิ่ง...ยิ่ง...)**
โครงสร้าง: 越 + V/Adj + 越 + V/Adj
1. 越学**越**难。Yuè xué **yuè** nán. → ยิ่งเรียนยิ่งยาก
2. 他越说越快。Tā yuè shuō yuè kuài. → เขายิ่งพูดยิ่งเร็ว
3. 我越来越喜欢中文了。Wǒ yuè lái yuè xǐhuān Zhōngwén le. → ฉันชอบภาษาจีนมากขึ้นเรื่อยๆ
4. 天气越来越冷。Tiānqì yuè lái yuè lěng. → อากาศหนาวขึ้นเรื่อยๆ

**3. 比...还/更... (ยิ่งกว่า)**
1. 今天比昨天**还**冷。Jīntiān bǐ zuótiān **hái** lěng. → วันนี้หนาวยิ่งกว่าเมื่อวานอีก
2. 他比我**更**用功。Tā bǐ wǒ **gèng** yōnggōng. → เขาพยายามมากกว่าฉนยิ่งกว่าเดิม

## 💬 บทสนทนา

### บทสนทนา 1: เปรียบเทียบเมือง

**游客 (Yóukè):** 北京和上海，你觉得哪个城市更好？
Běijīng hé Shànghǎi, nǐ juéde nǎge chéngshì gèng hǎo?
ปักกิ่งกับเซี่ยงไฮ้ คุณคิดว่าเมืองไหนดีกว่า?

**当地人 (Dāngdìrén):** 我觉得各有优点。北京比上海历史更悠久，但上海比北京更现代。
Wǒ juéde gè yǒu yōudiǎn. Běijīng bǐ Shànghǎi lìshǐ gèng yōujiǔ, dàn Shànghǎi bǐ Běijīng gèng xiàndài.
ผมคิดว่าแต่ละที่มีข้อดีของตัวเอง ปักกิ่งมีประวัติศาสตร์ยาวนานกว่าเซี่ยงไฮ้ แต่เซี่ยงไฮ้ทันสมัยกว่าปักกิ่ง

**游客:** 天气呢？北京的冬天比上海冷多了吧？
Tiānqì ne? Běijīng de dōngtiān bǐ Shànghǎi lěng duō le ba?
แล้วอากาศล่ะ? ฤดูหนาวของปักกิ่งหนาวกว่าเซี่ยงไฮ้มากใช่ไหม?

**当地人:** 是的，北京冬天比上海冷得多。但北京的夏天没有上海那么潮湿。
Shì de, Běijīng dōngtiān bǐ Shànghǎi lěng de duō. Dàn Běijīng de xiàtiān méiyǒu Shànghǎi nàme cháoshī.
ใช่ครับ ฤดูหนาวปักกิ่งหนาวกว่าเซี่ยงไฮ้มาก แต่ฤดูร้อนปักกิ่งไม่ชื้นเท่าเซี่ยงไฮ้

**游客:** 那物价呢？
Nà wùjià ne?
แล้วราคาสินค้าล่ะ?

**当地人:** 上海的生活费比北京贵一点儿，但两个城市都比其他城市贵。
Shànghǎi de shēnghuó fèi bǐ Běijīng guì yīdiǎnr, dàn liǎng gè chéngshì dōu bǐ qítā chéngshì guì.
ค่าครองชีพเซี่ยงไฮ้แพงกว่าปักกิ่งนิดหน่อย แต่ทั้งสองเมืองก็แพงกว่าเมืองอื่นๆ ทั้งนั้น

### บทสนทนา 2: เปรียบเทียบสินค้า

**顾客 (Gùkè):** 这两件衬衫有什么区别？
Zhè liǎng jiàn chènshān yǒu shénme qūbié?
เสื้อเชิ้ตสองตัวนี้มีอะไรแตกต่างกันบ้าง?

**店员 (Diànyuán):** 这件比那件贵一百块，但质量好得多。
Zhè jiàn bǐ nà jiàn guì yī bǎi kuài, dàn zhìliàng hǎo de duō.
ตัวนี้แพงกว่าตัวนั้นร้อยหยวน แต่คุณภาพดีกว่ามาก

**顾客:** 那件没有这件好吗？
Nà jiàn méiyǒu zhè jiàn hǎo ma?
ตัวนั้นไม่ดีเท่าตัวนี้เหรอ?

**店员:** 对，那件不如这件耐穿。这件是最好的款式，很多顾客都喜欢。
Duì, nà jiàn bùrú zhè jiàn nài chuān. Zhè jiàn shì zuì hǎo de kuǎnshì, hěn duō gùkè dōu xǐhuān.
ใช่ครับ ตัวนั้นทนน้อยกว่าตัวนี้ ตัวนี้เป็นดีไซน์ที่ดีที่สุด ลูกค้าหลายคนชอบมาก

**顾客:** 好，我就买这件。
Hǎo, wǒ jiù mǎi zhè jiàn.
โอเค ฉันซื้อตัวนี้เลย

### บทสนทนา 3: เปรียบเทียบภาษา

**朋友 (Péngyǒu):** 你觉得中文和泰文，哪个更难学？
Nǐ juéde Zhōngwén hé Tàiwén, nǎge gèng nán xué?
คุณคิดว่าภาษาจีนกับภาษาไทย ภาษาไหนยากกว่ากัน?

**我 (Wǒ):** 对泰国人来说，中文比泰文难多了。
Duì Tàiguó rén lái shuō, Zhōngwén bǐ Tàiwén nán duō le.
สำหรับคนไทย ภาษาจีนยากกว่าภาษาไทยมากเลย

**朋友:** 那中文比英文难吗？
Nà Zhōngwén bǐ Yīngwén nán ma?
แล้วภาษาจีนยากกว่าภาษาอังกฤษไหม?

**我:** 中文和英文不一样，各有难点。但我觉得中文的声调是最难的部分。
Zhōngwén hé Yīngwén bù yīyàng, gè yǒu nándiǎn. Dàn wǒ juéde Zhōngwén de shēngdiào shì zuì nán de bùfen.
ภาษาจีนกับภาษาอังกฤษไม่เหมือนกัน แต่ละภาษาก็มีความยากของตัวเอง แต่ฉันคิดว่าวรรณยุกต์ภาษาจีนเป็นส่วนที่ยากที่สุด

**朋友:** 越学越有趣吧？
Yuè xué yuè yǒuqù ba?
ยิ่งเรียนยิ่งน่าสนใจขึ้นเรื่อยๆ ใช่ไหม?

**我:** 对，越学越喜欢！
Duì, yuè xué yuè xǐhuān!
ใช่เลย ยิ่งเรียนยิ่งชอบ!

### บทสนทนา 4: เปรียบเทียบตัวเอง

**面试官 (Miànshìguān):** 你觉得自己的优势是什么？
Nǐ juéde zìjǐ de yōushì shì shénme?
คุณคิดว่าจุดแข็งของคุณคืออะไร?

**求职者 (Qiúzhízhě):** 我比其他候选人有更多的工作经验。我做了五年的这方面工作。
Wǒ bǐ qítā hòuxuǎnrén yǒu gèng duō de gōngzuò jīngyàn. Wǒ zuò le wǔ nián de zhè fāngmiàn gōngzuò.
ฉันมีประสบการณ์ทำงานมากกว่าผู้สมัครคนอื่น ฉันทำงานในด้านนี้มาห้าปีแล้ว

**面试官:** 你的英语比中文好吗？
Nǐ de Yīngyǔ bǐ Zhōngwén hǎo ma?
ภาษาอังกฤษของคุณดีกว่าภาษาจีนไหม?

**求职者:** 差不多一样，两门语言我都很流利。我的英语和中文一样好。
Chàbuduō yīyàng, liǎng mén yǔyán wǒ dōu hěn liúlì. Wǒ de Yīngyǔ hé Zhōngwén yīyàng hǎo.
พอๆ กัน ทั้งสองภาษาฉันพูดได้คล่องมาก ภาษาอังกฤษและภาษาจีนของฉันดีเท่ากัน

### บทสนทนา 5: เปรียบเทียบอาหาร

**食客A (Shíkè A):** 你觉得这家还是那家餐厅更好？
Nǐ juéde zhè jiā háishi nà jiā cāntīng gèng hǎo?

**食客B (Shíkè B):** 我觉得那家比这家好吃得多，而且没有这家贵。
Wǒ juéde nà jiā bǐ zhè jiā hǎo chī de duō, érqiě méiyǒu zhè jiā guì.
ฉันคิดว่าร้านนั้นอร่อยกว่าร้านนี้มาก และก็ไม่แพงเท่าร้านนี้ด้วย

**食客A:** 真的吗？这家是本地最出名的餐厅啊！
Zhēn de ma? Zhè jiā shì běndì zuì chūmíng de cāntīng a!

**食客B:** 出名不代表最好吃。那家餐厅虽然不如这家有名，但菜比这家好吃。

### ชุดที่ 1: 比 (bǐ)
1. 苹果比香蕉甜。Píngguǒ bǐ xiāngjiāo tián. → แอปเปิ้ลหวานกว่ากล้วย
2. 他比我跑得快。Tā bǐ wǒ pǎo de kuài. → เขาวิ่งได้เร็วกว่าฉัน
3. 今天比昨天冷多了。Jīntiān bǐ zuótiān lěng duō le. → วันนี้หนาวกว่าเมื่อวานมาก
4. 这个比那个便宜一点儿。Zhège bǐ nàge piányí yīdiǎnr. → อันนี้ถูกกว่าอันนั้นนิดหน่อย
5. 学中文比学英文难。Xué Zhōngwén bǐ xué Yīngwén nán. → เรียนภาษาจีนยากกว่าเรียนภาษาอังกฤษ

### ชุดที่ 2: 没有 (méiyǒu)
6. 我没有他聪明。Wǒ méiyǒu tā cōngmíng. → ฉันไม่ฉลาดเท่าเขา
7. 今天没有昨天热。Jīntiān méiyǒu zuótiān rè. → วันนี้ไม่ร้อนเท่าเมื่อวาน
8. 这家店没有那家好。Zhè jiā diàn méiyǒu nà jiā hǎo. → ร้านนี้ไม่ดีเท่าร้านนั้น
9. 泰国没有中国大。Tàiguó méiyǒu Zhōngguó dà. → ประเทศไทยไม่ใหญ่เท่าจีน
10. 这本书没有那本有趣。Zhè běn shū méiyǒu nà běn yǒuqù. → หนังสือเล่มนี้ไม่น่าสนใจเท่าเล่มนั้น

### ชุดที่ 3: 一样 (yīyàng)
11. 我们俩的身高一样。Wǒmen liǎ de shēngāo yīyàng. → ส่วนสูงของเราสองคนเท่ากัน
12. 这两道菜味道一样好。Zhè liǎng dào cài wèidào yīyàng hǎo. → อาหารสองจานนี้รสชาติอร่อยเท่ากัน
13. 你跟他不一样高。Nǐ gēn tā bù yīyàng gāo. → คุณไม่ได้สูงเท่ากับเขา
14. 他们的想法和我的一样。Tāmen de xiǎngfǎ hé wǒ de yīyàng. → ความคิดของพวกเขาเหมือนกับของฉัน
15. 今天和昨天一样冷。Jīntiān hé zuótiān yīyàng lěng. → วันนี้หนาวเท่ากับเมื่อวาน

### ชุดที่ 4: 最/更/越
16. 这是世界上最高的山。Zhè shì shìjiè shàng zuì gāo de shān. → นี่เป็นภูเขาที่สูงที่สุดในโลก
17. 我越来越喜欢中国文化了。Wǒ yuè lái yuè xǐhuān Zhōngguó wénhuà le. → ฉันชอบวัฒนธรรมจีนมากขึ้นเรื่อยๆ
18. 他比我更用功。Tā bǐ wǒ gèng yōnggōng. → เขาขยันมากกว่าฉัน
19. 越说越快。Yuè shuō yuè kuài. → ยิ่งพูดยิ่งเร็ว
20. 这个方法最简单。Zhège fāngfǎ zuì jiǎndān. → วิธีนี้ง่ายที่สุด

### สรุปโครงสร้างเปรียบเทียบ

| โครงสร้าง | ความหมาย | ตัวอย่าง |
|---------|---------|---------|
| A 比 B + Adj | A มากกว่า B | 他比我高 |
| A 没有 B + Adj | A ไม่เท่า B | 我没有他高 |
| A 跟 B 一样 + Adj | A เหมือน B | 我们一样高 |
| A 不如 B | A ด้อยกว่า B | 我不如他聪明 |
| 最 + Adj | ที่สุด | 他最高 |
| 更 + Adj | ยิ่งมากขึ้น | 更好 |
| 越...越... | ยิ่ง...ยิ่ง... | 越学越好 |
| 越来越 + Adj | มากขึ้นเรื่อยๆ | 越来越好 |

### ข้อควรระวัง:
1. ❌ 他比我更高。(ผิดถ้าใช้ 更 กับ 比 โดยตรง)
2. ✅ 他比我高。/ 他比我高得多。
3. ❌ 他比我高得多一点。(ผิด)
4. ✅ 他比我高一点儿。/ 他比我高得多。

## 🔬 การเปรียบเทียบขั้นสูง: โครงสร้างซับซ้อน

### โครงสร้าง Superlative (ขั้นสุด)

| โครงสร้าง | ความหมาย | ตัวอย่าง | แปลไทย |
|----------|---------|---------|--------|
| 最 + Adj | ที่สุด | 他是班里最高的 | เขาสูงที่สุดในห้อง |
| 最 + Adj + 的 + N | N ที่...ที่สุด | 最贵的手机 | โทรศัพท์ที่แพงที่สุด |
| 最好的...之一 | หนึ่งในที่ดีที่สุด | 最好的学校之一 | หนึ่งในโรงเรียนที่ดีที่สุด |
| 最不 + Adj | ที่น้อยที่สุด | 最不贵的 | ที่ถูกที่สุด |
| 没有比...更 + Adj | ไม่มีสิ่งใดที่...กว่า | 没有比健康更重要的 | ไม่มีสิ่งใดสำคัญกว่าสุขภาพ |

   (Jīntiān bǐ zuótiān nuǎnhuo yīdiǎnr.)

   (Tā gōngzuò bǐ rènhé rén dōu nǔlì.)
   แปล: เขาทำงานขยันกว่าทุกคน

   (Zhège pǐnpái bǐ nà gè pǐnpái zhìliàng hǎo de duō.)
   แปล: แบรนด์นี้คุณภาพดีกว่าแบรนด์นั้นมาก

10. 坐飞机比坐火车快了好几个小时。
    (Zuò fēijī bǐ zuò huǒchē kuài le hǎo jǐ gè xiǎoshí.)

**กลุ่มที่ 2: 没有 (ไม่มีสิ่งใดที่...)**

11. 这家餐厅没有那家好吃。
    (Zhè jiā cāntīng méiyǒu nà jiā hǎochī.)
    แปล: ร้านอาหารนี้ไม่อร่อยเท่าร้านนั้น

12. 现在没有以前忙了。
    (Xiànzài méiyǒu yǐqián máng le.)
    แปล: ตอนนี้ไม่ยุ่งเท่าก่อน

13. 他没有我跑得快。
    (Tā méiyǒu wǒ pǎo de kuài.)
    แปล: เขาวิ่งได้ไม่เร็วเท่าฉัน

    (Jīnnián de chǎnliàng méiyǒu qùnián gāo.)

    (Zhè liǎng jiàn yīfú yánsè yīyàng, dàn kuǎnshì bùtóng.)

18. 他的中文说得跟中国人一样好。
    (Tā de Zhōngwén shuō de gēn Zhōngguó rén yīyàng hǎo.)

    (Tā xuéxí de tàidù hé yǐqián bù yīyàng le.)

**กลุ่มที่ 4: 越来越 (มากขึ้นเรื่อยๆ)**

21. 他的中文越来越好了。
    (Tā de Zhōngwén yuè lái yuè hǎo le.)
    แปล: ภาษาจีนของเขาดีขึ้นเรื่อยๆ

    (Tiānqì yuè lái yuè lěng le, yào duō chuān diǎn yīfú.)

    (Zhège chéngshì de fángjià yuè lái yuè gāo le.)
    แปล: ราคาบ้านในเมืองนี้สูงขึ้นเรื่อยๆ

24. 科技越来越发达，生活越来越方便。
    (Kējì yuè lái yuè fādá, shēnghuó yuè lái yuè fāngbiàn.)
    แปล: เทคโนโลยีก้าวหน้ามากขึ้นเรื่อยๆ ชีวิตสะดวกขึ้นเรื่อยๆ

25. 他越来越懒了，我很担心。
    (Tā yuè lái yuè lǎn le, wǒ hěn dānxīn.)
    แปล: เขาขี้เกียจขึ้นเรื่อยๆ ฉันกังวลมาก

**กลุ่มที่ 5: 越...越... (ยิ่ง...ยิ่ง...)**

    (Yuè xué yuè yǒu yìsi, Zhōngwén zhēn de hěn yǒuqù.)

แปล: คุณคิดว่าปักกิ่งกับเซี่ยงไฮ้ เมืองไหนเหมาะสำหรับการอาศัยอยู่มากกว่า?

(Wǒ juéde Shànghǎi bǐ Běijīng gèng guójì huà, shēnghuó yě gèng fāngbiàn.)
แปล: ฉันคิดว่าเซี่ยงไฮ้มีความเป็นนานาชาติมากกว่าปักกิ่ง ชีวิตก็สะดวกกว่าด้วย

**A:** 但北京的文化氛围没有上海那么商业化，我更喜欢北京。

**B:** 那倒是，北京的历史比上海悠久得多。
(Nà dào shì, Běijīng de lìshǐ bǐ Shànghǎi yōujiǔ de duō.)
แปล: ก็จริงนะ ประวัติศาสตร์ของปักกิ่งยาวนานกว่าเซี่ยงไฮ้มาก

**A:** 两个城市各有千秋，很难说哪个更好。

### บทสนทนาที่ 12: เปรียบเทียบวิธีการเรียน

**B:** 网上学习比去学校更灵活，可以随时随地学。
(Wǎng shàng xuéxí bǐ qù xuéxiào gèng línghuó, kěyǐ suíshí suídì xué.)

**A:** 没错，但是去学校上课互动性更强，学习效果可能更好。
(Méicuò, dànshì qù xuéxiào shàngkè hùdòng xìng gèng qiáng, xuéxí xiàoguǒ kěnéng gèng hǎo.)
แปล: ถูกต้อง แต่การไปโรงเรียนมีปฏิสัมพันธ์มากกว่า ผลการเรียนอาจดีกว่า

**B:** 这倒是。网上学习需要更强的自律性，不是每个人都适合。
(Zhè dào shì. Wǎng shàng xuéxí xūyào gèng qiáng de zìlǜ xìng, bù shì měi gè rén dōu shìhé.)
แปล: นั่นก็จริง การเรียนออนไลน์ต้องการวินัยในตัวเองมากกว่า ไม่ใช่ทุกคนที่เหมาะ

**A:** 所以两种方式结合起来可能效果最好。
(Suǒyǐ liǎng zhǒng fāngshì jiéhé qǐlái kěnéng xiàoguǒ zuì hǎo.)
แปล: ดังนั้นการผสมผสานสองวิธีเข้าด้วยกันอาจให้ผลดีที่สุด

### บทสนทนาที่ 13: เปรียบเทียบอาหาร

**A:** 四川菜和广东菜，你更喜欢哪个？
(Sìchuān cài hé Guǎngdōng cài, nǐ gèng xǐhuān nǎge?)

**A:** 但四川菜比广东菜更有味道，吃起来更过瘾。
(Dàn Sìchuān cài bǐ Guǎngdōng cài gèng yǒu wèidào, chī qǐlái gèng guòyǐn.)
แปล: แต่อาหารเสฉวนมีรสชาติมากกว่าอาหารกวางตุ้ง กินแล้วสะใจกว่า

## ⚠️ ข้อผิดพลาดที่พบบ่อยในการเปรียบเทียบ (25+ ข้อ)

### กลุ่มที่ 1: ข้อผิดพลาดกับ 比

1. ❌ 他比我更高。
   ✅ 他比我高。/ 他比我高得多。
   หมายเหตุ: ไม่ใช้ 更 หลัง 比 โดยตรง

2. ❌ 他比我高得多一点。
   ✅ 他比我高一点儿。(นิดเดียว) / 他比我高得多。(มาก)
   หมายเหตุ: ห้ามใช้ 得多 กับ 一点 ด้วยกัน

3. ❌ 我比他更不喜欢数学。
   ✅ 我没有他那么喜欢数学。
   หมายเหตุ: ใช้ 没有 แทนเมื่อเปรียบเทียบสิ่งที่น้อยกว่า

4. ❌ A比B更不如C。
   ✅ A不如B，也不如C。
   หมายเหตุ: 不如 ใช้แบบง่ายไม่ซ้อน

5. ❌ 我比他们两个都高。
   ✅ 我比他们两个都高。(ถูก!)
   หมายเหตุ: โครงสร้างนี้ถูกต้องแล้ว

6. ❌ 她比我漂亮很多。
   ✅ 她比我漂亮多了。/ 她比我漂亮得多。
   หมายเหตุ: ใช้ 多了 หรือ 得多 ไม่ใช่ 很多

7. ❌ 今天的天气比昨天好了一点。
   ✅ 今天的天气比昨天好一点儿。
   หมายเหตุ: ไม่ใช้ 了 ระหว่าง 好 กับ 一点

### กลุ่มที่ 2: ข้อผิดพลาดกับ 没有

8. ❌ 他没有我聪明得多。
   ✅ 他没有我聪明。/ 他远不如我聪明。
   หมายเหตุ: 没有 ไม่ใช้ 得多

9. ❌ 这里没有那里那么冷一点。
   ✅ 这里没有那里冷。/ 这里比那里暖和一点。
   หมายเหตุ: 没有...那么 + Adj แล้วไม่ต่อด้วย 一点

10. ❌ A没有B好吃比C。
    ✅ A没有B好吃，也没有C好吃。
    หมายเหตุ: ไม่ผสม 没有 กับ 比 ในประโยคเดียวกัน

### กลุ่มที่ 3: ข้อผิดพลาดกับ 越来越 และ 越...越...

11. ❌ 越来越更好。
    ✅ 越来越好。
    หมายเหตุ: ไม่ใช้ 更 หลัง 越来越

12. ❌ 他越努力，越他变聪明。
    ✅ 他越努力，越聪明。
    หมายเหตุ: 越...越... ไม่ต้องใส่ Subject ซ้ำ

13. ❌ 越来越的好。
    ✅ 越来越好。
    หมายเหตุ: ไม่ต้องใส่ 的

### กลุ่มที่ 4: ข้อผิดพลาดทั่วไป

14. ❌ 我跟他一样高比你。
    ✅ 我跟他一样高，比你高。
    หมายเหตุ: ต้องแยกสองประโยค

15. ❌ 他是最高比我们。
    ✅ 他是我们中最高的。/ 他比我们都高。
    หมายเหตุ: ใช้ 中 แสดงกลุ่ม

16. ❌ 两个都比较好，我喜欢更前面那个。
    ✅ 两个都不错，我更喜欢前面那个。
    หมายเหตุ: 更 + 喜欢 ไม่ใช่ 喜欢 + 更

17. ❌ 她不如我大两岁。
    ✅ 她比我小两岁。/ 我比她大两岁。
    หมายเหตุ: 不如 ไม่ใช้กับตัวเลขโดยตรง

18. ❌ 苹果比香蕉更甜一些。
    ✅ 苹果比香蕉甜一些。
    หมายเหตุ: ไม่ใช้ 更 และ 一些 ด้วยกันกับ 比

## 🏋️ แบบฝึกหัดการเปรียบเทียบ (60+ ข้อ)

### ชุดที่ 1: สร้างประโยคเปรียบเทียบ (ใช้ 比)

เปลี่ยนข้อมูลต่อไปนี้เป็นประโยคเปรียบเทียบด้วย 比:

1. 小明 175cm / 小红 160cm → 小明比小红高十五厘米。
2. 苹果5元/个 / 香蕉3元/个 → 苹果比香蕉贵两块钱。
3. 北京 -5°C / 上海 5°C → 北京比上海冷十度。
4. 火车 3小时 / 飞机 1小时 → 飞机比火车快两个小时。
5. 今天的作业 10题 / 昨天的作业 5题 → 今天的作业比昨天多一倍。

### ชุดที่ 2: แก้ไขประโยคผิด

4. 他没有我高比你。→ ___

### ชุดที่ 3: เติมคำที่ขาด

7. 我比他高，也___她高。(比/没有/更)

### ชุดที่ 4: แปลเป็นภาษาจีน

แปลประโยคต่อไปนี้โดยใช้โครงสร้างเปรียบเทียบที่เหมาะสม:

2. เธอวิ่งไม่เร็วเท่าฉัน

4. เขาสูงเท่ากับพ่อ
5. โทรศัพท์รุ่นนี้แพงกว่ารุ่นนั้นสามร้อยหยวน
6. ภาษาจีนของเขาดีขึ้นเรื่อยๆ
7. ร้านอาหารนี้ไม่อร่อยเท่าร้านนั้น
8. เธอสวยที่สุดในห้อง
9. ยิ่งยุ่งยิ่งต้องระวังสุขภาพ
10. ฤดูหนาวปีนี้หนาวกว่าปีที่แล้วมาก

### ชุดที่ 5: ประโยคเปรียบเทียบจากชีวิตจริง (ฝึกพูด)

ฝึกสร้างประโยคเปรียบเทียบเกี่ยวกับตัวเอง:

1. เปรียบเทียบตัวเองกับพี่หรือน้อง
2. เปรียบเทียบงานสองอย่างที่คุณเคยทำ
3. เปรียบเทียบเมืองสองเมืองที่คุณรู้จัก
4. เปรียบเทียบอาหารสองอย่างที่คุณชอบ
5. เปรียบเทียบตัวเองตอนนี้กับตอนที่เริ่มเรียนภาษาจีน

## 📌 หมายเหตุวัฒนธรรม: การเปรียบเทียบในสังคมจีน

การเปรียบเทียบเป็นส่วนหนึ่งของวัฒนธรรมการสื่อสารในจีน พ่อแม่ชาวจีนมักเปรียบเทียบลูกกับ "ลูกคนอื่น" (别人家的孩子 biéren jiā de háizi) เพื่อกระตุ้นให้พยายามมากขึ้น ซึ่งบางครั้งสร้างแรงกดดันให้เด็ก ในธุรกิจ การเปรียบเทียบราคาและคุณภาพเป็นทักษะสำคัญในการต่อรอง สำนวนที่ใช้บ่อยคือ **货比三家** (huò bǐ sān jiā) แปลว่า "เปรียบเทียบสินค้าจากสามร้าน" หมายถึงการเปรียบเทียบก่อนซื้อ
